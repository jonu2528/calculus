4.5 การประยุกต์อินทิกรัล (Applications of Integrals)

อินทิกรัลมีการประยุกต์มากมายในคณิตศาสตร์และวิทยาศาสตร์ ในบทนี้เราจะศึกษาการหาพื้นที่ระหว่างเส้นโค้ง ปริมาตรของทรงหมุน และความยาวเส้นโค้ง

1. พื้นที่ระหว่างเส้นโค้ง (Area Between Curves)

สูตรพื้นที่ระหว่างเส้นโค้ง

พื้นที่ระหว่างกราฟ \(y = f(x)\) และ \(y = g(x)\) ตั้งแต่ \(x = a\) ถึง \(x = b\):

\[A = \int_a^b |f(x) - g(x)| \, dx\]

ถ้า \(f(x) \geq g(x)\) ตลอดช่วง \([a, b]\):

\[A = \int_a^b [f(x) - g(x)] \, dx\]

ตัวอย่าง 1

จงหาพื้นที่ระหว่างกราฟ \(y = x^2\) และ \(y = x\)

วิธีทำ

ขั้นที่ 1: หาจุดตัด

\[x^2 = x \Rightarrow x^2 - x = 0 \Rightarrow x(x-1) = 0 \Rightarrow x = 0, 1\]

ขั้นที่ 2: พิจารณาว่ากราฟใดอยู่บน

ในช่วง \([0, 1]\): \(x \geq x^2\) (เช่น \(x = 0.5\): \(0.5 > 0.25\))

ขั้นที่ 3: คำนวณพื้นที่

\[A = \int_0^1 (x - x^2) \, dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1\]
\[= \frac{1}{2} - \frac{1}{3} = \frac{3-2}{6} = \frac{1}{6} \text{ ตารางหน่วย}\]

ตัวอย่าง 2

จงหาพื้นที่ระหว่างกราฟ \(y = x^2 - 4\) และ \(y = -x^2 + 4\)

วิธีทำ

ขั้นที่ 1: หาจุดตัด

\[x^2 - 4 = -x^2 + 4 \Rightarrow 2x^2 = 8 \Rightarrow x = \pm 2\]

ขั้นที่ 2: กราฟบน: \(-x^2 + 4 \geq x^2 - 4\) ในช่วง \([-2, 2]\)

ขั้นที่ 3: คำนวณ

\[A = \int_{-2}^{2} [(-x^2 + 4) - (x^2 - 4)] \, dx = \int_{-2}^{2} (-2x^2 + 8) \, dx\]
\[= \left[-\frac{2x^3}{3} + 8x\right]_{-2}^{2}\]
\[= \left(-\frac{16}{3} + 16\right) - \left(\frac{16}{3} - 16\right) = -\frac{32}{3} + 32 = \frac{64}{3} \text{ ตารางหน่วย}\]

ตัวอย่าง 3

จงหาพื้นที่ระหว่างกราฟ \(y = \sin x\) และ \(y = \cos x\) ตั้งแต่ \(x = 0\) ถึง \(x = \frac{\pi}{2}\)

วิธีทำ

ขั้นที่ 1: หาจุดตัด

\[\sin x = \cos x \Rightarrow x = \frac{\pi}{4}\]

ขั้นที่ 2: พิจารณาช่วง

  • \([0, \frac{\pi}{4}]\): \(\cos x \geq \sin x\)
  • \([\frac{\pi}{4}, \frac{\pi}{2}]\): \(\sin x \geq \cos x\)

ขั้นที่ 3: คำนวณ

\[A = \int_0^{\pi/4} (\cos x - \sin x) \, dx + \int_{\pi/4}^{\pi/2} (\sin x - \cos x) \, dx\]
\[= \left[\sin x + \cos x\right]_0^{\pi/4} + \left[-\cos x - \sin x\right]_{\pi/4}^{\pi/2}\]
\[= \left(\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2} - 0 - 1\right) + \left(0 - 1 + \frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}\right)\]
\[= (\sqrt{2} - 1) + (\sqrt{2} - 1) = 2\sqrt{2} - 2 \approx 0.828 \text{ ตารางหน่วย}\]

2. ปริมาตรของทรงหมุน (Volumes of Revolution)

แนวคิด

เมื่อหมุนพื้นที่รอบแกนจะได้ทรงสามมิติ ปริมาตรหาได้โดยการอินทิเกรต

วิธีแผ่นดิสก์ (Disk Method)

หมุนรอบแกน \(x\):

\[V = \pi\int_a^b [f(x)]^2 \, dx\]

หมุนรอบแกน \(y\):

\[V = \pi\int_c^d [g(y)]^2 \, dy\]

วิธีวงแหวน (Washer Method)

เมื่อมีช่องว่างตรงกลาง (หมุนพื้นที่ระหว่างสองเส้นโค้ง):

\[V = \pi\int_a^b \left([R(x)]^2 - [r(x)]^2\right) dx\]

โดย \(R(x)\) = รัศมีนอก, \(r(x)\) = รัศมีใน

ตัวอย่าง 4

จงหาปริมาตรที่เกิดจากการหมุนพื้นที่ใต้กราฟ \(y = \sqrt{x}\) ตั้งแต่ \(x = 0\) ถึง \(x = 4\) รอบแกน \(x\)

วิธีทำ

ใช้วิธีแผ่นดิสก์:

\[V = \pi\int_0^4 (\sqrt{x})^2 \, dx = \pi\int_0^4 x \, dx\]
\[= \pi\left[\frac{x^2}{2}\right]_0^4 = \pi \cdot \frac{16}{2} = 8\pi \text{ ลูกบาศก์หน่วย}\]

ตัวอย่าง 5

จงหาปริมาตรทรงกรวยที่มีฐานรัศมี \(r\) และสูง \(h\)

วิธีทำ

วางกรวยให้จุดยอดอยู่ที่จุดกำเนิด ฐานอยู่ที่ \(x = h\)

สมการขอบกรวย: \(y = \frac{r}{h}x\)

\[V = \pi\int_0^h \left(\frac{r}{h}x\right)^2 dx = \pi\frac{r^2}{h^2}\int_0^h x^2 \, dx\]
\[= \frac{\pi r^2}{h^2}\left[\frac{x^3}{3}\right]_0^h = \frac{\pi r^2}{h^2} \cdot \frac{h^3}{3} = \frac{1}{3}\pi r^2 h\]

ซึ่งตรงกับสูตร \(V = \frac{1}{3}\pi r^2 h\) ที่เราคุ้นเคย!

ตัวอย่าง 6

จงหาปริมาตรที่เกิดจากการหมุนพื้นที่ระหว่าง \(y = x^2\) และ \(y = x\) รอบแกน \(x\)

วิธีทำ

จุดตัด: \(x = 0\) และ \(x = 1\)

ในช่วง \([0, 1]\): \(x \geq x^2\)

ใช้วิธีวงแหวน: \(R = x\), \(r = x^2\)

\[V = \pi\int_0^1 [x^2 - (x^2)^2] \, dx = \pi\int_0^1 (x^2 - x^4) \, dx\]
\[= \pi\left[\frac{x^3}{3} - \frac{x^5}{5}\right]_0^1 = \pi\left(\frac{1}{3} - \frac{1}{5}\right) = \pi \cdot \frac{2}{15} = \frac{2\pi}{15}\]

วิธีเปลือกทรงกระบอก (Shell Method)

หมุนรอบแกน \(y\):

\[V = 2\pi\int_a^b x \cdot f(x) \, dx\]

ตัวอย่าง 7

จงหาปริมาตรที่เกิดจากการหมุนพื้นที่ใต้กราฟ \(y = x^2\) ตั้งแต่ \(x = 0\) ถึง \(x = 2\) รอบแกน \(y\)

วิธีทำ

ใช้วิธีเปลือกทรงกระบอก:

\[V = 2\pi\int_0^2 x \cdot x^2 \, dx = 2\pi\int_0^2 x^3 \, dx\]
\[= 2\pi\left[\frac{x^4}{4}\right]_0^2 = 2\pi \cdot \frac{16}{4} = 8\pi \text{ ลูกบาศก์หน่วย}\]

3. ความยาวเส้นโค้ง (Arc Length)

สูตรความยาวเส้นโค้ง

ความยาวของเส้นโค้ง \(y = f(x)\) ตั้งแต่ \(x = a\) ถึง \(x = b\):

\[L = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2} \, dx = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx\]

ตัวอย่าง 8

จงหาความยาวของเส้นโค้ง \(y = x^{3/2}\) ตั้งแต่ \(x = 0\) ถึง \(x = 4\)

วิธีทำ

ขั้นที่ 1: หาอนุพันธ์

\[\frac{dy}{dx} = \frac{3}{2}x^{1/2} = \frac{3}{2}\sqrt{x}\]
\[\left(\frac{dy}{dx}\right)^2 = \frac{9}{4}x\]

ขั้นที่ 2: ตั้งอินทิกรัล

\[L = \int_0^4 \sqrt{1 + \frac{9x}{4}} \, dx\]

ขั้นที่ 3: แทนค่า

ให้ \(u = 1 + \frac{9x}{4}\), \(du = \frac{9}{4}dx\), \(dx = \frac{4}{9}du\)

  • \(x = 0\): \(u = 1\)
  • \(x = 4\): \(u = 10\)
\[L = \int_1^{10} \sqrt{u} \cdot \frac{4}{9} \, du = \frac{4}{9}\left[\frac{2}{3}u^{3/2}\right]_1^{10}\]
\[= \frac{8}{27}\left(10^{3/2} - 1\right) = \frac{8}{27}(10\sqrt{10} - 1) \approx 9.07\]

ตัวอย่าง 9

จงหาความยาวของเส้นตรง \(y = 3x + 2\) ตั้งแต่ \(x = 0\) ถึง \(x = 4\)

วิธีทำ

\(\displaystyle\frac{dy}{dx} = 3\)

\[L = \int_0^4 \sqrt{1 + 9} \, dx = \int_0^4 \sqrt{10} \, dx = \sqrt{10} \cdot 4 = 4\sqrt{10}\]

ตรวจสอบ: ใช้ทฤษฎีบทพีทาโกรัส

\[L = \sqrt{4^2 + 12^2} = \sqrt{16 + 144} = \sqrt{160} = 4\sqrt{10} \quad \checkmark\]

4. พื้นที่ผิวของทรงหมุน (Surface Area of Revolution)

สูตรพื้นที่ผิว

พื้นที่ผิวที่เกิดจากการหมุนเส้นโค้ง \(y = f(x)\) รอบแกน \(x\):

\[S = 2\pi\int_a^b f(x)\sqrt{1 + [f'(x)]^2} \, dx\]

ตัวอย่าง 10

จงหาพื้นที่ผิวของทรงกลมรัศมี \(r\)

วิธีทำ

ครึ่งวงกลม: \(y = \sqrt{r^2 - x^2}\), \(x \in [-r, r]\)

\[\frac{dy}{dx} = \frac{-x}{\sqrt{r^2 - x^2}}\]
\[1 + \left(\frac{dy}{dx}\right)^2 = 1 + \frac{x^2}{r^2 - x^2} = \frac{r^2}{r^2 - x^2}\]
\[S = 2\pi\int_{-r}^r \sqrt{r^2 - x^2} \cdot \frac{r}{\sqrt{r^2 - x^2}} \, dx = 2\pi\int_{-r}^r r \, dx\]
\[= 2\pi r \cdot [x]_{-r}^r = 2\pi r (2r) = 4\pi r^2\]

ซึ่งตรงกับสูตรพื้นที่ผิวทรงกลม \(S = 4\pi r^2\)

สรุป

สูตรสำคัญ

การประยุกต์ สูตร
พื้นที่ระหว่างเส้นโค้ง \(\displaystyle A = \int_a^b |f(x) - g(x)| \, dx\)
ปริมาตร (Disk) \(\displaystyle V = \pi\int_a^b [f(x)]^2 \, dx\)
ปริมาตร (Washer) \(\displaystyle V = \pi\int_a^b [R^2 - r^2] \, dx\)
ปริมาตร (Shell) \(\displaystyle V = 2\pi\int_a^b x \cdot f(x) \, dx\)
ความยาวเส้นโค้ง \(\displaystyle L = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx\)
พื้นที่ผิว \(\displaystyle S = 2\pi\int_a^b f(x)\sqrt{1 + [f'(x)]^2} \, dx\)

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหาพื้นที่ระหว่างกราฟ \(y = x^2\) และ \(y = 2x\)

จุดตัด: \(x^2 = 2x \Rightarrow x = 0, 2\)

\[A = \int_0^2 (2x - x^2) \, dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = 4 - \frac{8}{3} = \frac{4}{3}\]

แบบฝึกหัดที่ 2

จงหาปริมาตรที่เกิดจากการหมุนพื้นที่ใต้กราฟ \(y = x^3\) ตั้งแต่ \(x = 0\) ถึง \(x = 1\) รอบแกน \(x\)

\[V = \pi\int_0^1 (x^3)^2 \, dx = \pi\int_0^1 x^6 \, dx = \pi\left[\frac{x^7}{7}\right]_0^1 = \frac{\pi}{7}\]

แบบฝึกหัดที่ 3

จงหาปริมาตรที่เกิดจากการหมุนพื้นที่ระหว่าง \(y = x\) และ \(y = x^2\) รอบแกน \(y\)

ใช้วิธี Shell: จุดตัด \(x = 0, 1\)

\[V = 2\pi\int_0^1 x(x - x^2) \, dx = 2\pi\int_0^1 (x^2 - x^3) \, dx\]
\[= 2\pi\left[\frac{x^3}{3} - \frac{x^4}{4}\right]_0^1 = 2\pi\left(\frac{1}{3} - \frac{1}{4}\right) = 2\pi \cdot \frac{1}{12} = \frac{\pi}{6}\]

แบบฝึกหัดที่ 4

จงหาความยาวของเส้นโค้ง \(y = \frac{2}{3}x^{3/2}\) ตั้งแต่ \(x = 0\) ถึง \(x = 3\)

\(\displaystyle\frac{dy}{dx} = x^{1/2} = \sqrt{x}\)

\[L = \int_0^3 \sqrt{1 + x} \, dx = \left[\frac{2}{3}(1+x)^{3/2}\right]_0^3\]
\[= \frac{2}{3}(8 - 1) = \frac{14}{3}\]

แบบฝึกหัดที่ 5

จงหาพื้นที่ผิวที่เกิดจากการหมุนเส้นโค้ง \(y = \sqrt{x}\) ตั้งแต่ \(x = 0\) ถึง \(x = 1\) รอบแกน \(x\)

\(\displaystyle\frac{dy}{dx} = \frac{1}{2\sqrt{x}}\), \(\displaystyle 1 + \left(\frac{dy}{dx}\right)^2 = 1 + \frac{1}{4x} = \frac{4x+1}{4x}\)

\[S = 2\pi\int_0^1 \sqrt{x} \cdot \sqrt{\frac{4x+1}{4x}} \, dx = 2\pi\int_0^1 \frac{\sqrt{4x+1}}{2} \, dx\]
\[= \pi\left[\frac{(4x+1)^{3/2}}{6}\right]_0^1 = \frac{\pi}{6}(5\sqrt{5} - 1)\]
