5.1 อินทิเกรตทีละส่วน (Integration by Parts)

การอินทิเกรตทีละส่วนเป็นเทคนิคที่ใช้อินทิเกรตผลคูณของฟังก์ชันสองฟังก์ชัน โดยใช้หลักการย้อนกลับของกฎผลคูณในการหาอนุพันธ์

1. สูตรการอินทิเกรตทีละส่วน

ที่มาของสูตร

จากกฎผลคูณ (Product Rule):

\[\frac{d}{dx}[uv] = u\frac{dv}{dx} + v\frac{du}{dx}\]

อินทิเกรตทั้งสองข้าง:

\[uv = \int u \, dv + \int v \, du\]

จัดรูปใหม่:

\[\int u \, dv = uv - \int v \, du\]

สูตรการอินทิเกรตทีละส่วน

\[\int u \, dv = uv - \int v \, du\]

สำหรับอินทิกรัลจำกัดเขต:

\[\int_a^b u \, dv = \Big[uv\Big]_a^b - \int_a^b v \, du\]

วิธีเลือก u และ dv: กฎ LIATE

เลือก \(u\) จากฟังก์ชันที่มาก่อนในลำดับนี้:

  1. L - Logarithmic functions (\(\ln x\), \(\log x\))
  2. I - Inverse trigonometric functions (\(\arcsin x\), \(\arctan x\))
  3. A - Algebraic functions (\(x^n\), พหุนาม)
  4. T - Trigonometric functions (\(\sin x\), \(\cos x\))
  5. E - Exponential functions (\(e^x\), \(a^x\))

ส่วนที่เหลือคือ \(dv\)

2. ตัวอย่างพื้นฐาน

ตัวอย่าง 1

จงหา \(\displaystyle\int x e^x \, dx\)

วิธีทำ

ขั้นที่ 1: เลือก \(u\) และ \(dv\)

ใช้ LIATE: \(x\) (Algebraic) มาก่อน \(e^x\) (Exponential)

  • \(u = x\) \(\Rightarrow\) \(du = dx\)
  • \(dv = e^x \, dx\) \(\Rightarrow\) \(v = e^x\)

ขั้นที่ 2: ใช้สูตร

\[\int x e^x \, dx = xe^x - \int e^x \, dx = xe^x - e^x + C\]
\[= e^x(x - 1) + C\]

ตัวอย่าง 2

จงหา \(\displaystyle\int x \cos x \, dx\)

วิธีทำ

\(u = x\), \(dv = \cos x \, dx\)

\(du = dx\), \(v = \sin x\)

\[\int x \cos x \, dx = x\sin x - \int \sin x \, dx\]
\[= x\sin x + \cos x + C\]

ตัวอย่าง 3

จงหา \(\displaystyle\int \ln x \, dx\)

วิธีทำ

เขียนเป็น \(\int \ln x \cdot 1 \, dx\)

\(u = \ln x\), \(dv = dx\)

\(du = \frac{1}{x}dx\), \(v = x\)

\[\int \ln x \, dx = x\ln x - \int x \cdot \frac{1}{x} \, dx\]
\[= x\ln x - \int dx = x\ln x - x + C\]
\[= x(\ln x - 1) + C\]

ตัวอย่าง 4

จงหา \(\displaystyle\int \arctan x \, dx\)

วิธีทำ

\(u = \arctan x\), \(dv = dx\)

\(du = \frac{1}{1+x^2}dx\), \(v = x\)

\[\int \arctan x \, dx = x\arctan x - \int \frac{x}{1+x^2} \, dx\]

สำหรับอินทิกรัลที่สอง ให้ \(w = 1 + x^2\), \(dw = 2x \, dx\)

\[\int \frac{x}{1+x^2} \, dx = \frac{1}{2}\ln(1+x^2)\]

ดังนั้น:

\[\int \arctan x \, dx = x\arctan x - \frac{1}{2}\ln(1+x^2) + C\]

3. การอินทิเกรตทีละส่วนซ้ำ

เมื่อต้องใช้ซ้ำหลายครั้ง

บางอินทิกรัลต้องใช้การอินทิเกรตทีละส่วนมากกว่าหนึ่งครั้ง โดยเฉพาะเมื่อ \(u\) เป็นพหุนามกำลังสูง

ตัวอย่าง 5

จงหา \(\displaystyle\int x^2 e^x \, dx\)

วิธีทำ

รอบที่ 1:

\(u = x^2\), \(dv = e^x \, dx\)

\(du = 2x \, dx\), \(v = e^x\)

\[\int x^2 e^x \, dx = x^2 e^x - 2\int x e^x \, dx\]

รอบที่ 2: (จากตัวอย่าง 1)

\[\int x e^x \, dx = e^x(x - 1)\]

รวมผล:

\[\int x^2 e^x \, dx = x^2 e^x - 2e^x(x - 1) + C\]
\[= e^x(x^2 - 2x + 2) + C\]

ตัวอย่าง 6

จงหา \(\displaystyle\int x^2 \sin x \, dx\)

วิธีทำ

รอบที่ 1:

\(u = x^2\), \(dv = \sin x \, dx\), \(du = 2x \, dx\), \(v = -\cos x\)

\[\int x^2 \sin x \, dx = -x^2\cos x + 2\int x\cos x \, dx\]

รอบที่ 2:

\(u = x\), \(dv = \cos x \, dx\), \(du = dx\), \(v = \sin x\)

\[\int x\cos x \, dx = x\sin x - \int \sin x \, dx = x\sin x + \cos x\]

รวมผล:

\[\int x^2 \sin x \, dx = -x^2\cos x + 2(x\sin x + \cos x) + C\]
\[= -x^2\cos x + 2x\sin x + 2\cos x + C\]

4. การอินทิเกรตทีละส่วนแบบวน (Cyclic)

แนวคิด

บางครั้งการอินทิเกรตทีละส่วนจะวนกลับมาที่อินทิกรัลเดิม ในกรณีนี้ให้ตั้งสมการแก้หาอินทิกรัล

ตัวอย่าง 7

จงหา \(\displaystyle\int e^x \sin x \, dx\)

วิธีทำ

ให้ \(I = \int e^x \sin x \, dx\)

รอบที่ 1:

\(u = e^x\), \(dv = \sin x \, dx\)

\(du = e^x \, dx\), \(v = -\cos x\)

\[I = -e^x\cos x + \int e^x\cos x \, dx\]

รอบที่ 2:

\(u = e^x\), \(dv = \cos x \, dx\)

\(du = e^x \, dx\), \(v = \sin x\)

\[\int e^x\cos x \, dx = e^x\sin x - \int e^x\sin x \, dx = e^x\sin x - I\]

รวมผล:

\[I = -e^x\cos x + e^x\sin x - I\]
\[2I = e^x(\sin x - \cos x)\]
\[I = \frac{e^x(\sin x - \cos x)}{2} + C\]

ตัวอย่าง 8

จงหา \(\displaystyle\int e^x \cos x \, dx\)

วิธีทำ

ให้ \(I = \int e^x \cos x \, dx\)

รอบที่ 1:

\[I = e^x\sin x - \int e^x\sin x \, dx\]

รอบที่ 2:

\[\int e^x\sin x \, dx = -e^x\cos x + \int e^x\cos x \, dx = -e^x\cos x + I\]

รวมผล:

\[I = e^x\sin x - (-e^x\cos x + I)\]
\[I = e^x\sin x + e^x\cos x - I\]
\[2I = e^x(\sin x + \cos x)\]
\[I = \frac{e^x(\sin x + \cos x)}{2} + C\]

5. อินทิกรัลจำกัดเขต

ตัวอย่าง 9

จงหา \(\displaystyle\int_0^1 xe^{-x} \, dx\)

วิธีทำ

\(u = x\), \(dv = e^{-x} \, dx\)

\(du = dx\), \(v = -e^{-x}\)

\[\int_0^1 xe^{-x} \, dx = \Big[-xe^{-x}\Big]_0^1 + \int_0^1 e^{-x} \, dx\]
\[= (-e^{-1} - 0) + \Big[-e^{-x}\Big]_0^1\]
\[= -e^{-1} + (-e^{-1} + 1) = 1 - 2e^{-1} = 1 - \frac{2}{e}\]

ตัวอย่าง 10

จงหา \(\displaystyle\int_1^e x \ln x \, dx\)

วิธีทำ

\(u = \ln x\), \(dv = x \, dx\)

\(du = \frac{1}{x}dx\), \(v = \frac{x^2}{2}\)

\[\int_1^e x\ln x \, dx = \left[\frac{x^2\ln x}{2}\right]_1^e - \int_1^e \frac{x}{2} \, dx\]
\[= \left(\frac{e^2 \cdot 1}{2} - 0\right) - \left[\frac{x^2}{4}\right]_1^e\]
\[= \frac{e^2}{2} - \frac{e^2 - 1}{4} = \frac{2e^2 - e^2 + 1}{4} = \frac{e^2 + 1}{4}\]

สรุป

ประเด็นสำคัญ

  • สูตร: \(\displaystyle\int u \, dv = uv - \int v \, du\)
  • ใช้กฎ LIATE ในการเลือก \(u\): Logarithmic, Inverse trig, Algebraic, Trigonometric, Exponential
  • บางครั้งต้องใช้ซ้ำหลายครั้ง (เมื่อ \(u\) เป็นพหุนามกำลังสูง)
  • กรณีวน (cyclic): ตั้งสมการแก้หาอินทิกรัล
  • สำหรับอินทิกรัลจำกัดเขต: แทนค่าขอบเขตที่พจน์ \(uv\)

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหา \(\displaystyle\int x e^{2x} \, dx\)

\(u = x\), \(dv = e^{2x}dx\), \(du = dx\), \(v = \frac{1}{2}e^{2x}\)

\[\int xe^{2x}dx = \frac{x}{2}e^{2x} - \frac{1}{2}\int e^{2x}dx = \frac{x}{2}e^{2x} - \frac{1}{4}e^{2x} + C\]
\[= \frac{e^{2x}(2x-1)}{4} + C\]

แบบฝึกหัดที่ 2

จงหา \(\displaystyle\int x \sin 2x \, dx\)

\(u = x\), \(dv = \sin 2x \, dx\), \(v = -\frac{1}{2}\cos 2x\)

\[\int x\sin 2x \, dx = -\frac{x}{2}\cos 2x + \frac{1}{2}\int\cos 2x \, dx\]
\[= -\frac{x}{2}\cos 2x + \frac{1}{4}\sin 2x + C\]

แบบฝึกหัดที่ 3

จงหา \(\displaystyle\int (\ln x)^2 \, dx\)

\(u = (\ln x)^2\), \(dv = dx\), \(du = \frac{2\ln x}{x}dx\), \(v = x\)

\[\int (\ln x)^2 dx = x(\ln x)^2 - 2\int \ln x \, dx\]

จากตัวอย่าง 3: \(\int \ln x \, dx = x(\ln x - 1)\)

\[= x(\ln x)^2 - 2x(\ln x - 1) + C = x[(\ln x)^2 - 2\ln x + 2] + C\]

แบบฝึกหัดที่ 4

จงหา \(\displaystyle\int \arcsin x \, dx\)

\(u = \arcsin x\), \(dv = dx\), \(du = \frac{1}{\sqrt{1-x^2}}dx\), \(v = x\)

\[\int \arcsin x \, dx = x\arcsin x - \int \frac{x}{\sqrt{1-x^2}} dx\]

ให้ \(w = 1-x^2\), \(dw = -2x \, dx\)

\[\int \frac{x}{\sqrt{1-x^2}} dx = -\frac{1}{2}\int w^{-1/2}dw = -\sqrt{w} = -\sqrt{1-x^2}\]
\[\int \arcsin x \, dx = x\arcsin x + \sqrt{1-x^2} + C\]

แบบฝึกหัดที่ 5

จงหา \(\displaystyle\int_0^{\pi} x^2\cos x \, dx\)

รอบที่ 1: \(u = x^2\), \(dv = \cos x \, dx\)

\[\int_0^{\pi} x^2\cos x \, dx = [x^2\sin x]_0^{\pi} - 2\int_0^{\pi} x\sin x \, dx = 0 - 2\int_0^{\pi} x\sin x \, dx\]

รอบที่ 2:

\[\int_0^{\pi} x\sin x \, dx = [-x\cos x]_0^{\pi} + \int_0^{\pi}\cos x \, dx = \pi + [\sin x]_0^{\pi} = \pi\]
\[\int_0^{\pi} x^2\cos x \, dx = -2\pi\]
