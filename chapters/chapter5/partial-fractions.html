5.4 เศษส่วนย่อย (Partial Fractions)

การแยกเศษส่วนย่อยเป็นเทคนิคที่ใช้อินทิเกรตเศษส่วนพหุนาม โดยแยกเศษส่วนที่ซับซ้อน ออกเป็นผลบวกของเศษส่วนที่ง่ายกว่าซึ่งอินทิเกรตได้โดยตรง

1. เงื่อนไขเบื้องต้น

Proper vs Improper Fractions

สำหรับ \(\frac{P(x)}{Q(x)}\):

  • Proper fraction: ดีกรีของ \(P(x)\) < ดีกรีของ \(Q(x)\)
  • Improper fraction: ดีกรีของ \(P(x)\) \(\geq\) ดีกรีของ \(Q(x)\)

ถ้าเป็น improper fraction ต้องหารยาวก่อน แล้วค่อยแยกเศษส่วนย่อยส่วนที่เหลือ

2. กรณีที่ 1: ตัวประกอบเชิงเส้นต่างกัน (Distinct Linear Factors)

รูปแบบ

ถ้า \(Q(x) = (a_1x + b_1)(a_2x + b_2) \cdots (a_nx + b_n)\) แล้ว:

\[\frac{P(x)}{Q(x)} = \frac{A_1}{a_1x + b_1} + \frac{A_2}{a_2x + b_2} + \cdots + \frac{A_n}{a_nx + b_n}\]

ตัวอย่าง 1

จงหา \(\displaystyle\int \frac{1}{x^2 - 1} \, dx\)

วิธีทำ

ขั้นที่ 1: แยกตัวส่วน

\[x^2 - 1 = (x-1)(x+1)\]

ขั้นที่ 2: ตั้งเศษส่วนย่อย

\[\frac{1}{x^2 - 1} = \frac{A}{x-1} + \frac{B}{x+1}\]

ขั้นที่ 3: หาค่า A และ B

\[1 = A(x+1) + B(x-1)\]
  • แทน \(x = 1\): \(1 = A(2) + 0 \Rightarrow A = \frac{1}{2}\)
  • แทน \(x = -1\): \(1 = 0 + B(-2) \Rightarrow B = -\frac{1}{2}\)

ขั้นที่ 4: อินทิเกรต

\[\int \frac{1}{x^2 - 1} dx = \frac{1}{2}\int \frac{dx}{x-1} - \frac{1}{2}\int \frac{dx}{x+1}\]
\[= \frac{1}{2}\ln|x-1| - \frac{1}{2}\ln|x+1| + C = \frac{1}{2}\ln\left|\frac{x-1}{x+1}\right| + C\]

ตัวอย่าง 2

จงหา \(\displaystyle\int \frac{2x + 1}{x^2 + x - 2} \, dx\)

วิธีทำ

\(x^2 + x - 2 = (x+2)(x-1)\)

\[\frac{2x + 1}{(x+2)(x-1)} = \frac{A}{x+2} + \frac{B}{x-1}\]
\[2x + 1 = A(x-1) + B(x+2)\]
  • \(x = 1\): \(3 = 3B \Rightarrow B = 1\)
  • \(x = -2\): \(-3 = -3A \Rightarrow A = 1\)
\[\int \frac{2x + 1}{x^2 + x - 2} dx = \int \frac{dx}{x+2} + \int \frac{dx}{x-1}\]
\[= \ln|x+2| + \ln|x-1| + C = \ln|x^2 + x - 2| + C\]

3. กรณีที่ 2: ตัวประกอบเชิงเส้นซ้ำ (Repeated Linear Factors)

รูปแบบ

ถ้า \(Q(x)\) มีตัวประกอบ \((ax + b)^n\) แล้วต้องใช้:

\[\frac{A_1}{ax + b} + \frac{A_2}{(ax + b)^2} + \cdots + \frac{A_n}{(ax + b)^n}\]

ตัวอย่าง 3

จงหา \(\displaystyle\int \frac{x}{(x-1)^2} \, dx\)

วิธีทำ

\[\frac{x}{(x-1)^2} = \frac{A}{x-1} + \frac{B}{(x-1)^2}\]
\[x = A(x-1) + B\]
  • \(x = 1\): \(1 = B\)
  • เปรียบเทียบสัมประสิทธิ์ของ \(x\): \(1 = A\)
\[\int \frac{x}{(x-1)^2} dx = \int \frac{dx}{x-1} + \int \frac{dx}{(x-1)^2}\]
\[= \ln|x-1| - \frac{1}{x-1} + C\]

ตัวอย่าง 4

จงหา \(\displaystyle\int \frac{x^2 + 1}{x(x-1)^2} \, dx\)

วิธีทำ

\[\frac{x^2 + 1}{x(x-1)^2} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{(x-1)^2}\]
\[x^2 + 1 = A(x-1)^2 + Bx(x-1) + Cx\]
  • \(x = 0\): \(1 = A\)
  • \(x = 1\): \(2 = C\)
  • เปรียบเทียบสัมประสิทธิ์ \(x^2\): \(1 = A + B \Rightarrow B = 0\)
\[\int \frac{x^2 + 1}{x(x-1)^2} dx = \int \frac{dx}{x} + \int \frac{2dx}{(x-1)^2}\]
\[= \ln|x| - \frac{2}{x-1} + C\]

4. กรณีที่ 3: ตัวประกอบกำลังสองที่แยกไม่ได้

รูปแบบ

ถ้า \(Q(x)\) มีตัวประกอบ \(ax^2 + bx + c\) ที่ \(b^2 - 4ac < 0\):

\[\frac{Ax + B}{ax^2 + bx + c}\]

ตัวอย่าง 5

จงหา \(\displaystyle\int \frac{x}{x^2 + 4} \, dx\)

วิธีทำ

\(x^2 + 4\) แยกตัวประกอบไม่ได้ (irreducible)

สังเกตว่า \(\frac{d}{dx}(x^2 + 4) = 2x\)

\[\int \frac{x}{x^2 + 4} dx = \frac{1}{2}\int \frac{2x}{x^2 + 4} dx = \frac{1}{2}\ln(x^2 + 4) + C\]

ตัวอย่าง 6

จงหา \(\displaystyle\int \frac{2x + 3}{x^2 + 2x + 5} \, dx\)

วิธีทำ

แยกเป็นสองส่วน: \(\frac{d}{dx}(x^2 + 2x + 5) = 2x + 2\)

\[\frac{2x + 3}{x^2 + 2x + 5} = \frac{2x + 2}{x^2 + 2x + 5} + \frac{1}{x^2 + 2x + 5}\]

ส่วนแรก:

\[\int \frac{2x + 2}{x^2 + 2x + 5} dx = \ln(x^2 + 2x + 5)\]

ส่วนที่สอง: ทำให้เป็นกำลังสองสมบูรณ์

\[x^2 + 2x + 5 = (x + 1)^2 + 4\]
\[\int \frac{dx}{(x+1)^2 + 4} = \frac{1}{2}\arctan\frac{x+1}{2}\]

คำตอบ:

\[\int \frac{2x + 3}{x^2 + 2x + 5} dx = \ln(x^2 + 2x + 5) + \frac{1}{2}\arctan\frac{x+1}{2} + C\]

ตัวอย่าง 7

จงหา \(\displaystyle\int \frac{x + 1}{(x-1)(x^2 + 1)} \, dx\)

วิธีทำ

\[\frac{x + 1}{(x-1)(x^2 + 1)} = \frac{A}{x-1} + \frac{Bx + C}{x^2 + 1}\]
\[x + 1 = A(x^2 + 1) + (Bx + C)(x - 1)\]
  • \(x = 1\): \(2 = 2A \Rightarrow A = 1\)
  • สัมประสิทธิ์ \(x^2\): \(0 = A + B \Rightarrow B = -1\)
  • ค่าคงที่: \(1 = A - C \Rightarrow C = 0\)
\[\int \frac{x + 1}{(x-1)(x^2 + 1)} dx = \int \frac{dx}{x-1} - \int \frac{x}{x^2 + 1} dx\]
\[= \ln|x-1| - \frac{1}{2}\ln(x^2 + 1) + C\]

5. กรณี Improper Fraction

ตัวอย่าง 8

จงหา \(\displaystyle\int \frac{x^3 + 2}{x^2 - 1} \, dx\)

วิธีทำ

ขั้นที่ 1: หารยาว (เพราะดีกรีเศษ = 3 > ดีกรีส่วน = 2)

\[\frac{x^3 + 2}{x^2 - 1} = x + \frac{x + 2}{x^2 - 1}\]

ขั้นที่ 2: แยกเศษส่วนย่อย

\[\frac{x + 2}{(x-1)(x+1)} = \frac{A}{x-1} + \frac{B}{x+1}\]
  • \(x = 1\): \(3 = 2A \Rightarrow A = \frac{3}{2}\)
  • \(x = -1\): \(1 = -2B \Rightarrow B = -\frac{1}{2}\)

ขั้นที่ 3: อินทิเกรต

\[\int \frac{x^3 + 2}{x^2 - 1} dx = \int x \, dx + \frac{3}{2}\int \frac{dx}{x-1} - \frac{1}{2}\int \frac{dx}{x+1}\]
\[= \frac{x^2}{2} + \frac{3}{2}\ln|x-1| - \frac{1}{2}\ln|x+1| + C\]

สรุป

ขั้นตอนการแยกเศษส่วนย่อย

  1. ตรวจสอบว่าเป็น proper fraction หรือไม่ (ถ้าไม่ใช่ ให้หารยาวก่อน)
  2. แยกตัวประกอบของตัวส่วน
  3. เขียนเศษส่วนย่อยตามรูปแบบที่เหมาะสม:
    • ตัวประกอบเชิงเส้นต่างกัน: \(\frac{A}{ax+b}\)
    • ตัวประกอบเชิงเส้นซ้ำ: \(\frac{A_1}{ax+b} + \frac{A_2}{(ax+b)^2} + ...\)
    • ตัวประกอบกำลังสองที่แยกไม่ได้: \(\frac{Ax+B}{ax^2+bx+c}\)
  4. หาค่าสัมประสิทธิ์โดยการแทนค่าหรือเปรียบเทียบสัมประสิทธิ์
  5. อินทิเกรตแต่ละเศษส่วนย่อย

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหา \(\displaystyle\int \frac{5x - 3}{x^2 - 2x - 3} \, dx\)

\(x^2 - 2x - 3 = (x-3)(x+1)\)

\[\frac{5x - 3}{(x-3)(x+1)} = \frac{A}{x-3} + \frac{B}{x+1}\]

\(x = 3\): \(12 = 4A \Rightarrow A = 3\)

\(x = -1\): \(-8 = -4B \Rightarrow B = 2\)

\[\int = 3\ln|x-3| + 2\ln|x+1| + C\]

แบบฝึกหัดที่ 2

จงหา \(\displaystyle\int \frac{3x + 5}{(x+1)^2} \, dx\)

\[\frac{3x + 5}{(x+1)^2} = \frac{A}{x+1} + \frac{B}{(x+1)^2}\]

\(3x + 5 = A(x+1) + B\)

\(x = -1\): \(2 = B\)

สัมประสิทธิ์ \(x\): \(A = 3\)

\[\int = 3\ln|x+1| - \frac{2}{x+1} + C\]

แบบฝึกหัดที่ 3

จงหา \(\displaystyle\int \frac{1}{x^3 - x} \, dx\)

\(x^3 - x = x(x-1)(x+1)\)

\[\frac{1}{x(x-1)(x+1)} = \frac{A}{x} + \frac{B}{x-1} + \frac{C}{x+1}\]

\(x = 0\): \(1 = -A \Rightarrow A = -1\)

\(x = 1\): \(1 = 2B \Rightarrow B = \frac{1}{2}\)

\(x = -1\): \(1 = -2C \Rightarrow C = \frac{1}{2}\)

\[\int = -\ln|x| + \frac{1}{2}\ln|x-1| + \frac{1}{2}\ln|x+1| + C\]

แบบฝึกหัดที่ 4

จงหา \(\displaystyle\int \frac{x^2}{x^2 + 4} \, dx\)

หารยาว: \(\frac{x^2}{x^2 + 4} = 1 - \frac{4}{x^2 + 4}\)

\[\int \left(1 - \frac{4}{x^2 + 4}\right) dx = x - 4 \cdot \frac{1}{2}\arctan\frac{x}{2} + C\]
\[= x - 2\arctan\frac{x}{2} + C\]

แบบฝึกหัดที่ 5

จงหา \(\displaystyle\int \frac{x^2 + 2x + 3}{(x-1)(x^2 + 1)} \, dx\)

\[\frac{x^2 + 2x + 3}{(x-1)(x^2 + 1)} = \frac{A}{x-1} + \frac{Bx + C}{x^2 + 1}\]

\(x = 1\): \(6 = 2A \Rightarrow A = 3\)

สัมประสิทธิ์ \(x^2\): \(1 = A + B \Rightarrow B = -2\)

ค่าคงที่: \(3 = -A + C \Rightarrow C = 6\)

\[\int = 3\ln|x-1| - \ln(x^2+1) + 6\arctan x + C\]
