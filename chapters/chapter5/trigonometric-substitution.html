5.3 การแทนค่าตรีโกณมิติ (Trigonometric Substitution)

การแทนค่าตรีโกณมิติเป็นเทคนิคที่ใช้เมื่ออินทิกรัลมีรากที่สองของนิพจน์กำลังสอง โดยใช้เอกลักษณ์ตรีโกณมิติเพื่อกำจัดรากที่สอง

1. เมื่อไหร่ควรใช้การแทนค่าตรีโกณมิติ

ตารางการแทนค่า

นิพจน์ในอินทิกรัล การแทนค่า เอกลักษณ์ที่ใช้
\(\sqrt{a^2 - x^2}\) \(x = a\sin\theta\) \(1 - \sin^2\theta = \cos^2\theta\)
\(\sqrt{a^2 + x^2}\) \(x = a\tan\theta\) \(1 + \tan^2\theta = \sec^2\theta\)
\(\sqrt{x^2 - a^2}\) \(x = a\sec\theta\) \(\sec^2\theta - 1 = \tan^2\theta\)

ขั้นตอนการทำ

  1. ระบุรูปแบบของนิพจน์และเลือกการแทนค่าที่เหมาะสม
  2. หา \(dx\) จากการแทนค่า
  3. แปลงนิพจน์ทั้งหมดเป็น \(\theta\)
  4. อินทิเกรตในรูป \(\theta\)
  5. แปลงคำตอบกลับเป็น \(x\)

2. กรณี \(\sqrt{a^2 - x^2}\)

ตัวอย่าง 1

จงหา \(\displaystyle\int \frac{dx}{\sqrt{9 - x^2}}\)

วิธีทำ

ขั้นที่ 1: เลือกการแทนค่า

\(a = 3\), ให้ \(x = 3\sin\theta\), \(dx = 3\cos\theta \, d\theta\)

ขั้นที่ 2: แปลงรากที่สอง

\[\sqrt{9 - x^2} = \sqrt{9 - 9\sin^2\theta} = 3\sqrt{1 - \sin^2\theta} = 3\cos\theta\]

ขั้นที่ 3: อินทิเกรต

\[\int \frac{dx}{\sqrt{9 - x^2}} = \int \frac{3\cos\theta}{3\cos\theta} d\theta = \int d\theta = \theta + C\]

ขั้นที่ 4: แปลงกลับ

จาก \(x = 3\sin\theta\) ดังนั้น \(\theta = \arcsin\frac{x}{3}\)

\[\int \frac{dx}{\sqrt{9 - x^2}} = \arcsin\frac{x}{3} + C\]

ตัวอย่าง 2

จงหา \(\displaystyle\int \sqrt{4 - x^2} \, dx\)

วิธีทำ

ให้ \(x = 2\sin\theta\), \(dx = 2\cos\theta \, d\theta\)

\[\sqrt{4 - x^2} = 2\cos\theta\]
\[\int \sqrt{4 - x^2} \, dx = \int 2\cos\theta \cdot 2\cos\theta \, d\theta = 4\int \cos^2\theta \, d\theta\]
\[= 4 \cdot \frac{1}{2}\int (1 + \cos 2\theta) d\theta = 2\left(\theta + \frac{\sin 2\theta}{2}\right) + C\]
\[= 2\theta + \sin 2\theta + C = 2\theta + 2\sin\theta\cos\theta + C\]

แปลงกลับ:

\(\sin\theta = \frac{x}{2}\), \(\cos\theta = \frac{\sqrt{4-x^2}}{2}\), \(\theta = \arcsin\frac{x}{2}\)

\[= 2\arcsin\frac{x}{2} + 2 \cdot \frac{x}{2} \cdot \frac{\sqrt{4-x^2}}{2} + C\]
\[= 2\arcsin\frac{x}{2} + \frac{x\sqrt{4-x^2}}{2} + C\]

3. กรณี \(\sqrt{a^2 + x^2}\)

ตัวอย่าง 3

จงหา \(\displaystyle\int \frac{dx}{\sqrt{x^2 + 4}}\)

วิธีทำ

ให้ \(x = 2\tan\theta\), \(dx = 2\sec^2\theta \, d\theta\)

\[\sqrt{x^2 + 4} = \sqrt{4\tan^2\theta + 4} = 2\sqrt{\tan^2\theta + 1} = 2\sec\theta\]
\[\int \frac{dx}{\sqrt{x^2 + 4}} = \int \frac{2\sec^2\theta}{2\sec\theta} d\theta = \int \sec\theta \, d\theta\]
\[= \ln|\sec\theta + \tan\theta| + C\]

แปลงกลับ:

\(\tan\theta = \frac{x}{2}\), \(\sec\theta = \frac{\sqrt{x^2+4}}{2}\)

\[= \ln\left|\frac{\sqrt{x^2+4}}{2} + \frac{x}{2}\right| + C = \ln\left|\frac{\sqrt{x^2+4} + x}{2}\right| + C\]
\[= \ln|\sqrt{x^2+4} + x| - \ln 2 + C = \ln|\sqrt{x^2+4} + x| + C'\]

ตัวอย่าง 4

จงหา \(\displaystyle\int \frac{x^2}{\sqrt{x^2 + 9}} \, dx\)

วิธีทำ

ให้ \(x = 3\tan\theta\), \(dx = 3\sec^2\theta \, d\theta\)

\[\sqrt{x^2 + 9} = 3\sec\theta\]
\[\int \frac{x^2}{\sqrt{x^2 + 9}} dx = \int \frac{9\tan^2\theta}{3\sec\theta} \cdot 3\sec^2\theta \, d\theta\]
\[= 9\int \tan^2\theta \sec\theta \, d\theta = 9\int (\sec^2\theta - 1)\sec\theta \, d\theta\]
\[= 9\int (\sec^3\theta - \sec\theta) d\theta\]

ใช้ผลลัพธ์ \(\int \sec^3\theta \, d\theta = \frac{1}{2}[\sec\theta\tan\theta + \ln|\sec\theta + \tan\theta|]\)

\[= 9\left[\frac{1}{2}(\sec\theta\tan\theta + \ln|\sec\theta + \tan\theta|) - \ln|\sec\theta + \tan\theta|\right] + C\]
\[= \frac{9}{2}\sec\theta\tan\theta - \frac{9}{2}\ln|\sec\theta + \tan\theta| + C\]

แปลงกลับ:

\[= \frac{9}{2} \cdot \frac{\sqrt{x^2+9}}{3} \cdot \frac{x}{3} - \frac{9}{2}\ln\left|\frac{\sqrt{x^2+9} + x}{3}\right| + C\]
\[= \frac{x\sqrt{x^2+9}}{2} - \frac{9}{2}\ln|\sqrt{x^2+9} + x| + C'\]

4. กรณี \(\sqrt{x^2 - a^2}\)

ตัวอย่าง 5

จงหา \(\displaystyle\int \frac{dx}{x\sqrt{x^2 - 4}}\)

วิธีทำ

ให้ \(x = 2\sec\theta\), \(dx = 2\sec\theta\tan\theta \, d\theta\)

\[\sqrt{x^2 - 4} = \sqrt{4\sec^2\theta - 4} = 2\sqrt{\sec^2\theta - 1} = 2\tan\theta\]
\[\int \frac{dx}{x\sqrt{x^2-4}} = \int \frac{2\sec\theta\tan\theta}{2\sec\theta \cdot 2\tan\theta} d\theta = \frac{1}{2}\int d\theta = \frac{\theta}{2} + C\]

แปลงกลับ:

จาก \(\sec\theta = \frac{x}{2}\) ดังนั้น \(\theta = \sec^{-1}\frac{x}{2}\)

\[\int \frac{dx}{x\sqrt{x^2-4}} = \frac{1}{2}\sec^{-1}\frac{x}{2} + C\]

ตัวอย่าง 6

จงหา \(\displaystyle\int \sqrt{x^2 - 9} \, dx\)

วิธีทำ

ให้ \(x = 3\sec\theta\), \(dx = 3\sec\theta\tan\theta \, d\theta\)

\[\sqrt{x^2 - 9} = 3\tan\theta\]
\[\int \sqrt{x^2 - 9} \, dx = \int 3\tan\theta \cdot 3\sec\theta\tan\theta \, d\theta = 9\int \tan^2\theta\sec\theta \, d\theta\]
\[= 9\int (\sec^2\theta - 1)\sec\theta \, d\theta = 9\int (\sec^3\theta - \sec\theta) d\theta\]
\[= 9\left[\frac{1}{2}(\sec\theta\tan\theta + \ln|\sec\theta + \tan\theta|) - \ln|\sec\theta + \tan\theta|\right] + C\]
\[= \frac{9}{2}\sec\theta\tan\theta - \frac{9}{2}\ln|\sec\theta + \tan\theta| + C\]

แปลงกลับ: \(\sec\theta = \frac{x}{3}\), \(\tan\theta = \frac{\sqrt{x^2-9}}{3}\)

\[= \frac{9}{2} \cdot \frac{x}{3} \cdot \frac{\sqrt{x^2-9}}{3} - \frac{9}{2}\ln\left|\frac{x + \sqrt{x^2-9}}{3}\right| + C\]
\[= \frac{x\sqrt{x^2-9}}{2} - \frac{9}{2}\ln|x + \sqrt{x^2-9}| + C'\]

5. การทำให้เป็นกำลังสองสมบูรณ์

แนวคิด

เมื่อนิพจน์ไม่อยู่ในรูปมาตรฐาน ให้ทำให้เป็นกำลังสองสมบูรณ์ก่อน

ตัวอย่าง 7

จงหา \(\displaystyle\int \frac{dx}{\sqrt{x^2 + 4x + 8}}\)

วิธีทำ

ขั้นที่ 1: ทำให้เป็นกำลังสองสมบูรณ์

\[x^2 + 4x + 8 = (x^2 + 4x + 4) + 4 = (x + 2)^2 + 4\]

ขั้นที่ 2: แทนค่า \(u = x + 2\)

\[\int \frac{dx}{\sqrt{(x+2)^2 + 4}} = \int \frac{du}{\sqrt{u^2 + 4}}\]

ขั้นที่ 3: ใช้การแทนค่าตรีโกณมิติ \(u = 2\tan\theta\)

\[= \ln|u + \sqrt{u^2 + 4}| + C\]
\[= \ln|(x+2) + \sqrt{x^2 + 4x + 8}| + C\]

สรุป

การเลือกการแทนค่า

  • \(\sqrt{a^2 - x^2}\) ใช้ \(x = a\sin\theta\)
  • \(\sqrt{a^2 + x^2}\) ใช้ \(x = a\tan\theta\)
  • \(\sqrt{x^2 - a^2}\) ใช้ \(x = a\sec\theta\)
  • ถ้าไม่อยู่ในรูปมาตรฐาน ให้ทำให้เป็นกำลังสองสมบูรณ์ก่อน
  • อย่าลืมแปลงคำตอบกลับเป็น \(x\)

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหา \(\displaystyle\int \frac{dx}{\sqrt{16 - x^2}}\)

ให้ \(x = 4\sin\theta\)

\[\int \frac{dx}{\sqrt{16 - x^2}} = \arcsin\frac{x}{4} + C\]

แบบฝึกหัดที่ 2

จงหา \(\displaystyle\int \frac{x^2}{\sqrt{1 - x^2}} \, dx\)

ให้ \(x = \sin\theta\)

\[\int \frac{\sin^2\theta}{\cos\theta} \cdot \cos\theta \, d\theta = \int \sin^2\theta \, d\theta = \frac{\theta}{2} - \frac{\sin 2\theta}{4} + C\]
\[= \frac{\arcsin x}{2} - \frac{x\sqrt{1-x^2}}{2} + C\]

แบบฝึกหัดที่ 3

จงหา \(\displaystyle\int \frac{dx}{x^2\sqrt{x^2 + 1}}\)

ให้ \(x = \tan\theta\), \(dx = \sec^2\theta \, d\theta\), \(\sqrt{x^2+1} = \sec\theta\)

\[\int \frac{\sec^2\theta}{\tan^2\theta \cdot \sec\theta} d\theta = \int \frac{\sec\theta}{\tan^2\theta} d\theta = \int \frac{\cos\theta}{\sin^2\theta} d\theta\]

ให้ \(u = \sin\theta\)

\[= -\frac{1}{\sin\theta} + C = -\csc\theta + C = -\frac{\sqrt{x^2+1}}{x} + C\]

แบบฝึกหัดที่ 4

จงหา \(\displaystyle\int \frac{\sqrt{x^2 - 1}}{x} \, dx\)

ให้ \(x = \sec\theta\)

\[\int \frac{\tan\theta}{\sec\theta} \cdot \sec\theta\tan\theta \, d\theta = \int \tan^2\theta \, d\theta\]
\[= \tan\theta - \theta + C = \sqrt{x^2-1} - \sec^{-1}x + C\]

แบบฝึกหัดที่ 5

จงหา \(\displaystyle\int \frac{dx}{\sqrt{x^2 - 6x + 13}}\)

ทำให้เป็นกำลังสองสมบูรณ์: \(x^2 - 6x + 13 = (x-3)^2 + 4\)

ให้ \(u = x - 3\)

\[\int \frac{du}{\sqrt{u^2 + 4}} = \ln|u + \sqrt{u^2+4}| + C\]
\[= \ln|(x-3) + \sqrt{x^2 - 6x + 13}| + C\]
