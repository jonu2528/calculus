# Calculus 1 Online - เว็บสอนแคลคูลัส 1 ออนไลน์

เว็บไซต์สอนวิชาแคลคูลัส 1 แบบครบถ้วน ด้วยเนื้อหาที่เข้าใจง่าย มีตัวอย่างและแบบฝึกหัดมากมาย รองรับการใช้งานแบบ Progressive Web App (PWA)

## 🎯 คุณสมบัติหลัก

- **เนื้อหาครบถ้วน** - ครอบคลุมทุกหัวข้อใน Calculus 1 แบ่งเป็น 5 บทหลัก
- **ตัวอย่างละเอียด** - แต่ละหัวข้อมีตัวอย่าง 5-7 ข้อ พร้อมวิธีทำทีละขั้นตอน
- **แบบฝึกหัดพร้อมเฉลย** - ฝึกได้ทันทีหลังเรียน มีปุ่มกดดูเฉลยละเอียด
- **Responsive Design** - ใช้งานได้ทุกอุปกรณ์ (คอมพิวเตอร์ แท็บเล็ต มือถือ)
- **Progress Tracking** - ติดตามความคืบหน้าการเรียนแบบ real-time
- **Search Functionality** - ค้นหาเนื้อหาได้ง่ายและรวดเร็ว
- **PWA Support** - ติดตั้งเป็นแอพบนมือถือได้ พร้อม offline support
- **LaTeX Math Rendering** - แสดงสมการทางคณิตศาสตร์ที่สวยงามด้วย MathJax

## 📚 โครงสร้างเนื้อหา

### บทที่ 1: ฟังก์ชัน ลิมิต และความต่อเนื่อง
**หัวข้อย่อย:**
1. **1.1 ฟังก์ชัน (Functions)** ✅ สร้างเสร็จแล้ว
   - ความหมายของฟังก์ชัน
   - โดเมน (domain) และพิสัย (range)
   - ฟังก์ชันประกอบ (composition of functions)
   - ฟังก์ชันผกผัน (inverse function)
   - การอ่านและแปลความหมายจากกราฟ

2. **1.2 ลิมิต (Limits)**
   - ความหมายเชิง intuitive ของลิมิต
   - ลิมิตด้านซ้ายและด้านขวา (one-sided limits)
   - กฎของลิมิต (limit laws)
   - ลิมิตรูปไม่กำหนด (0/0, ∞/∞)
   - ทฤษฎีบทบีบ (Squeeze Theorem)
   - นิยามเชิง ε-δ (เสริม)

3. **1.3 ความต่อเนื่อง (Continuity)**
   - นิยามฟังก์ชันต่อเนื่อง
   - ประเภทของความไม่ต่อเนื่อง
   - การตรวจสอบความต่อเนื่อง
   - ทฤษฎีบทค่ากลาง (Intermediate Value Theorem)

### บทที่ 2: อนุพันธ์ (Derivatives)
**หัวข้อย่อย:**
1. **2.1 ที่มาของอนุพันธ์**
   - อัตราการเปลี่ยนแปลงเฉลี่ย → อัตราการเปลี่ยนแปลงขณะหนึ่ง
   - นิยามอนุพันธ์จากลิมิต

2. **2.2 กฎพื้นฐานของอนุพันธ์**
   - นิยามอนุพันธ์ที่จุด
   - กฎผลบวกและผลต่าง
   - กฎคูณ (product rule)
   - กฎหาร (quotient rule)
   - กฎลูกโซ่ (chain rule)

3. **2.3 อนุพันธ์ของฟังก์ชันมาตรฐาน**
   - ฟังก์ชันพหุนาม (polynomial)
   - ฟังก์ชันเลขชี้กำลัง (exponential)
   - ฟังก์ชันลอการิทึม (logarithmic)
   - ฟังก์ชันตรีโกณมิติ (trigonometric)
   - ฟังก์ชันตรีโกณมิติผกผัน (inverse trigonometric)

4. **2.4 อนุพันธ์ขั้นสูง**
   - อนุพันธ์อันดับสูง (higher-order derivatives)
   - อนุพันธ์แบบปริยาย (implicit differentiation)
   - อนุพันธ์ของฟังก์ชันผกผัน

5. **2.5 ทฤษฎีบทสำคัญ**
   - ทฤษฎีบทค่าเฉลี่ย (Mean Value Theorem)
   - กฎของลอปิทาล (L'Hospital's Rule)

### บทที่ 3: การประยุกต์อนุพันธ์
**หัวข้อย่อย:**
1. **3.1 เรขาคณิตและกราฟ**
   - เส้นสัมผัส (tangent line) และเส้นตั้งฉาก (normal line)
   - ช่วงที่ฟังก์ชันเพิ่มและลด
   - ความเว้าโค้ง (concavity)
   - จุดเปลี่ยนเว้า (inflection point)

2. **3.2 ฟิสิกส์และการเคลื่อนที่**
   - ความสัมพันธ์ระหว่าง position, velocity, acceleration
   - ตัวอย่างโจทย์การเคลื่อนที่

3. **3.3 ค่าสูงสุดและต่ำสุด (Extrema)**
   - ค่าสูงสุดและต่ำสุดเฉพาะที่และสัมบูรณ์
   - การทดสอบด้วยอนุพันธ์อันดับแรกและสอง
   - ปัญหา optimization

4. **3.4 การประมาณค่า**
   - Linear approximation
   - Differentials
   - Newton's method (เสริม)

### บทที่ 4: ปริพันธ์และปริพันธ์จำกัดเขต
**หัวข้อย่อย:**
1. **4.1 ที่มาของปริพันธ์**
   - ความหมายจากพื้นที่ใต้กราฟ
   - Riemann sum

2. **4.2 ปริพันธ์ไม่จำกัดเขต (Indefinite Integrals)**
   - Antiderivative
   - สัญลักษณ์และค่าคงที่ +C

3. **4.3 ปริพันธ์จำกัดเขต (Definite Integrals)**
   - นิยามผ่าน Riemann sum
   - สมบัติของปริพันธ์จำกัดเขต
   - ทฤษฎีบทมูลฐานของแคลคูลัส (Fundamental Theorem of Calculus)

4. **4.4 ปริพันธ์ของฟังก์ชันมาตรฐาน**
   - ปริพันธ์ของ x^n, e^x, ln x
   - ปริพันธ์ของฟังก์ชันตรีโกณมิติ

5. **4.5 การแทนค่าตัวแปร (u-substitution)**
   - หลักการและตัวอย่าง
   - การเปลี่ยนขีดจำกัด

6. **4.6 การประยุกต์ปริพันธ์**
   - การหาพื้นที่ใต้กราฟ
   - พื้นที่ระหว่างสองเส้นโค้ง
   - ค่าเฉลี่ยของฟังก์ชัน

### บทที่ 5: เทคนิคการหาปริพันธ์
**หัวข้อย่อย:**
1. **5.1 Integration by Parts**
   - สูตรและวิธีการ
   - ตัวอย่างการใช้หลายครั้ง

2. **5.2 การแยกเศษส่วนย่อย (Partial Fractions)**
   - ตัวส่วนเป็นผลคูณของพหุนามเชิงเส้น
   - ตัวส่วนมีรากซ้ำ
   - ตัวส่วนเป็นพหุนามกำลังสอง

3. **5.3 ปริพันธ์ตรีโกณมิติ (Trig Integrals)**
   - ปริพันธ์ของ sin^m(x) cos^n(x)
   - ปริพันธ์ที่เกี่ยวกับ tan, sec

4. **5.4 การแทนค่าตรีโกณมิติ (Trig Substitution)**
   - รูปแบบ √(a² - x²), √(a² + x²), √(x² - a²)

5. **5.5 การแทนค่าตัวแปรใหม่ (General Substitution)**
   - เทคนิคการเลือกตัวแปรใหม่

6. **5.6 ปริพันธ์ไม่เหมาะสม (Improper Integrals)**
   - ขอบเขตเป็น ±∞
   - ฟังก์ชันมีจุดไม่ต่อเนื่อง

## 🚀 PWA (Progressive Web App)

### คุณสมบัติ PWA
- ✅ **Add to Home Screen** - ติดตั้งเป็นแอพบนมือถือได้

## 🧮 LaTeX และการแสดงสมการ

### MathJax
เว็บไซต์ใช้ MathJax 3 สำหรับแสดงสมการคณิตศาสตร์

### รูปแบบการเขียน
- **Inline math**: `$...$` หรือ `\(...\)`
  - ตัวอย่าง: `$f(x) = x^2$` แสดงเป็น $f(x) = x^2$

- **Display math**: `$$...$$` หรือ `\[...\]`
  - ตัวอย่าง:
    ```latex
    $$\int_a^b f(x)\,dx$$
    ```

### สัญลักษณ์ที่ใช้บ่อย
- `\int` - สัญลักษณ์ปริพันธ์ (∫)
- `\sum` - สัญลักษณ์ summation (Σ)
- `\sqrt{}` - รากที่สอง (√)
- `\frac{}{}` - เศษส่วน
- `\infty` - อนันต์ (∞)
- `\lim` - ลิมิต
- `\rightarrow` - ลูกศร (→)
