5.2 อินทิกรัลตรีโกณมิติ (Trigonometric Integrals)

ในบทนี้เราจะศึกษาเทคนิคการอินทิเกรตฟังก์ชันที่ประกอบด้วยฟังก์ชันตรีโกณมิติกำลังต่างๆ โดยใช้เอกลักษณ์ตรีโกณมิติและเทคนิคการแทนค่า

1. เอกลักษณ์ตรีโกณมิติที่ใช้บ่อย

เอกลักษณ์พื้นฐาน

  • \(\sin^2 x + \cos^2 x = 1\)
  • \(1 + \tan^2 x = \sec^2 x\)
  • \(1 + \cot^2 x = \csc^2 x\)

เอกลักษณ์ลดกำลัง (Power-Reducing)

  • \(\sin^2 x = \displaystyle\frac{1 - \cos 2x}{2}\)
  • \(\cos^2 x = \displaystyle\frac{1 + \cos 2x}{2}\)

เอกลักษณ์มุมสองเท่า

  • \(\sin 2x = 2\sin x \cos x\)
  • \(\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x\)

2. อินทิกรัลของ \(\sin^m x \cos^n x\)

กลยุทธ์

กรณี วิธีการ
\(m\) หรือ \(n\) เป็นจำนวนคี่ แยกตัวคี่ออกมา 1 ตัว ใช้ \(\sin^2 x + \cos^2 x = 1\) แล้วแทนค่า
\(m\) และ \(n\) เป็นจำนวนคู่ ใช้เอกลักษณ์ลดกำลัง

ตัวอย่าง 1

จงหา \(\displaystyle\int \sin^3 x \, dx\)

วิธีทำ

แยก \(\sin x\) ออก 1 ตัว:

\[\int \sin^3 x \, dx = \int \sin^2 x \cdot \sin x \, dx = \int (1 - \cos^2 x)\sin x \, dx\]

ให้ \(u = \cos x\), \(du = -\sin x \, dx\)

\[= -\int (1 - u^2) du = -u + \frac{u^3}{3} + C = -\cos x + \frac{\cos^3 x}{3} + C\]

ตัวอย่าง 2

จงหา \(\displaystyle\int \sin^2 x \cos^3 x \, dx\)

วิธีทำ

\(n = 3\) เป็นคี่ แยก \(\cos x\) ออก:

\[\int \sin^2 x \cos^3 x \, dx = \int \sin^2 x \cos^2 x \cdot \cos x \, dx\]
\[= \int \sin^2 x (1 - \sin^2 x) \cos x \, dx\]

ให้ \(u = \sin x\), \(du = \cos x \, dx\)

\[= \int u^2(1 - u^2) du = \int (u^2 - u^4) du = \frac{u^3}{3} - \frac{u^5}{5} + C\]
\[= \frac{\sin^3 x}{3} - \frac{\sin^5 x}{5} + C\]

ตัวอย่าง 3

จงหา \(\displaystyle\int \sin^2 x \, dx\)

วิธีทำ

ใช้เอกลักษณ์ลดกำลัง:

\[\sin^2 x = \frac{1 - \cos 2x}{2}\]
\[\int \sin^2 x \, dx = \int \frac{1 - \cos 2x}{2} dx = \frac{1}{2}\int (1 - \cos 2x) dx\]
\[= \frac{1}{2}\left(x - \frac{\sin 2x}{2}\right) + C = \frac{x}{2} - \frac{\sin 2x}{4} + C\]

ตัวอย่าง 4

จงหา \(\displaystyle\int \sin^2 x \cos^2 x \, dx\)

วิธีทำ

ทั้งคู่เป็นกำลังคู่ ใช้เอกลักษณ์:

\[\sin^2 x \cos^2 x = \frac{1}{4}\sin^2 2x = \frac{1}{4} \cdot \frac{1 - \cos 4x}{2} = \frac{1 - \cos 4x}{8}\]
\[\int \sin^2 x \cos^2 x \, dx = \frac{1}{8}\int (1 - \cos 4x) dx\]
\[= \frac{1}{8}\left(x - \frac{\sin 4x}{4}\right) + C = \frac{x}{8} - \frac{\sin 4x}{32} + C\]

3. อินทิกรัลของ \(\tan^m x \sec^n x\)

กลยุทธ์

กรณี วิธีการ
\(n\) เป็นคู่ แยก \(\sec^2 x\) ใช้ \(\sec^2 x = 1 + \tan^2 x\) แทน \(u = \tan x\)
\(m\) เป็นคี่ แยก \(\sec x \tan x\) ใช้ \(\tan^2 x = \sec^2 x - 1\) แทน \(u = \sec x\)

ตัวอย่าง 5

จงหา \(\displaystyle\int \tan^2 x \, dx\)

วิธีทำ

ใช้ \(\tan^2 x = \sec^2 x - 1\)

\[\int \tan^2 x \, dx = \int (\sec^2 x - 1) dx = \tan x - x + C\]

ตัวอย่าง 6

จงหา \(\displaystyle\int \tan^3 x \sec x \, dx\)

วิธีทำ

\(m = 3\) เป็นคี่ แยก \(\sec x \tan x\):

\[\int \tan^3 x \sec x \, dx = \int \tan^2 x \cdot \sec x \tan x \, dx\]
\[= \int (\sec^2 x - 1) \sec x \tan x \, dx\]

ให้ \(u = \sec x\), \(du = \sec x \tan x \, dx\)

\[= \int (u^2 - 1) du = \frac{u^3}{3} - u + C = \frac{\sec^3 x}{3} - \sec x + C\]

ตัวอย่าง 7

จงหา \(\displaystyle\int \tan^4 x \sec^4 x \, dx\)

วิธีทำ

\(n = 4\) เป็นคู่ แยก \(\sec^2 x\):

\[\int \tan^4 x \sec^4 x \, dx = \int \tan^4 x \sec^2 x \cdot \sec^2 x \, dx\]
\[= \int \tan^4 x (1 + \tan^2 x) \sec^2 x \, dx\]

ให้ \(u = \tan x\), \(du = \sec^2 x \, dx\)

\[= \int u^4(1 + u^2) du = \int (u^4 + u^6) du\]
\[= \frac{u^5}{5} + \frac{u^7}{7} + C = \frac{\tan^5 x}{5} + \frac{\tan^7 x}{7} + C\]

ตัวอย่าง 8

จงหา \(\displaystyle\int \sec^3 x \, dx\)

วิธีทำ

ใช้การอินทิเกรตทีละส่วน:

\(u = \sec x\), \(dv = \sec^2 x \, dx\), \(du = \sec x \tan x \, dx\), \(v = \tan x\)

\[\int \sec^3 x \, dx = \sec x \tan x - \int \sec x \tan^2 x \, dx\]
\[= \sec x \tan x - \int \sec x (\sec^2 x - 1) dx\]
\[= \sec x \tan x - \int \sec^3 x \, dx + \int \sec x \, dx\]

ให้ \(I = \int \sec^3 x \, dx\):

\[I = \sec x \tan x - I + \ln|\sec x + \tan x|\]
\[2I = \sec x \tan x + \ln|\sec x + \tan x|\]
\[I = \frac{1}{2}[\sec x \tan x + \ln|\sec x + \tan x|] + C\]

4. อินทิกรัลของผลคูณ sin และ cos ต่างมุม

สูตรผลคูณเป็นผลรวม

  • \(\sin A \cos B = \displaystyle\frac{1}{2}[\sin(A+B) + \sin(A-B)]\)
  • \(\sin A \sin B = \displaystyle\frac{1}{2}[\cos(A-B) - \cos(A+B)]\)
  • \(\cos A \cos B = \displaystyle\frac{1}{2}[\cos(A-B) + \cos(A+B)]\)

ตัวอย่าง 9

จงหา \(\displaystyle\int \sin 3x \cos 5x \, dx\)

วิธีทำ

ใช้สูตร: \(\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]\)

\[\sin 3x \cos 5x = \frac{1}{2}[\sin 8x + \sin(-2x)] = \frac{1}{2}[\sin 8x - \sin 2x]\]
\[\int \sin 3x \cos 5x \, dx = \frac{1}{2}\int (\sin 8x - \sin 2x) dx\]
\[= \frac{1}{2}\left(-\frac{\cos 8x}{8} + \frac{\cos 2x}{2}\right) + C\]
\[= -\frac{\cos 8x}{16} + \frac{\cos 2x}{4} + C\]

ตัวอย่าง 10

จงหา \(\displaystyle\int \cos 4x \cos 2x \, dx\)

วิธีทำ

\[\cos 4x \cos 2x = \frac{1}{2}[\cos(4x-2x) + \cos(4x+2x)] = \frac{1}{2}[\cos 2x + \cos 6x]\]
\[\int \cos 4x \cos 2x \, dx = \frac{1}{2}\int (\cos 2x + \cos 6x) dx\]
\[= \frac{1}{2}\left(\frac{\sin 2x}{2} + \frac{\sin 6x}{6}\right) + C = \frac{\sin 2x}{4} + \frac{\sin 6x}{12} + C\]

สรุป

กลยุทธ์หลัก

  • \(\sin^m x \cos^n x\) กำลังคี่: แยก 1 ตัว แปลงที่เหลือ แทนค่า
  • \(\sin^m x \cos^n x\) กำลังคู่ทั้งคู่: ใช้เอกลักษณ์ลดกำลัง
  • \(\tan^m x \sec^n x\) กำลังคู่ของ sec: แยก \(\sec^2 x\)
  • \(\tan^m x \sec^n x\) กำลังคี่ของ tan: แยก \(\sec x \tan x\)
  • ผลคูณต่างมุม: ใช้สูตรผลคูณเป็นผลรวม

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหา \(\displaystyle\int \cos^3 x \, dx\)

\[\int \cos^3 x \, dx = \int (1 - \sin^2 x)\cos x \, dx\]

ให้ \(u = \sin x\)

\[= \int (1 - u^2) du = u - \frac{u^3}{3} + C = \sin x - \frac{\sin^3 x}{3} + C\]

แบบฝึกหัดที่ 2

จงหา \(\displaystyle\int \cos^4 x \, dx\)

\[\cos^4 x = \left(\frac{1 + \cos 2x}{2}\right)^2 = \frac{1 + 2\cos 2x + \cos^2 2x}{4}\]
\[= \frac{1}{4} + \frac{\cos 2x}{2} + \frac{1 + \cos 4x}{8} = \frac{3}{8} + \frac{\cos 2x}{2} + \frac{\cos 4x}{8}\]
\[\int \cos^4 x \, dx = \frac{3x}{8} + \frac{\sin 2x}{4} + \frac{\sin 4x}{32} + C\]

แบบฝึกหัดที่ 3

จงหา \(\displaystyle\int \tan^3 x \, dx\)

\[\int \tan^3 x \, dx = \int \tan x \cdot \tan^2 x \, dx = \int \tan x (\sec^2 x - 1) dx\]
\[= \int \tan x \sec^2 x \, dx - \int \tan x \, dx\]
\[= \frac{\tan^2 x}{2} + \ln|\cos x| + C\]

แบบฝึกหัดที่ 4

จงหา \(\displaystyle\int \sin 2x \sin 4x \, dx\)

\[\sin 2x \sin 4x = \frac{1}{2}[\cos(2x-4x) - \cos(2x+4x)] = \frac{1}{2}[\cos(-2x) - \cos 6x]\]
\[= \frac{1}{2}[\cos 2x - \cos 6x]\]
\[\int \sin 2x \sin 4x \, dx = \frac{1}{2}\left(\frac{\sin 2x}{2} - \frac{\sin 6x}{6}\right) + C\]
\[= \frac{\sin 2x}{4} - \frac{\sin 6x}{12} + C\]

แบบฝึกหัดที่ 5

จงหา \(\displaystyle\int_0^{\pi/2} \sin^4 x \, dx\)

\[\sin^4 x = \left(\frac{1 - \cos 2x}{2}\right)^2 = \frac{1 - 2\cos 2x + \cos^2 2x}{4}\]
\[= \frac{1}{4} - \frac{\cos 2x}{2} + \frac{1 + \cos 4x}{8} = \frac{3}{8} - \frac{\cos 2x}{2} + \frac{\cos 4x}{8}\]
\[\int_0^{\pi/2} \sin^4 x \, dx = \left[\frac{3x}{8} - \frac{\sin 2x}{4} + \frac{\sin 4x}{32}\right]_0^{\pi/2}\]
\[= \frac{3\pi}{16} - 0 + 0 = \frac{3\pi}{16}\]
