4.1 แอนตี้อนุพันธ์ (Antiderivatives)

แอนตี้อนุพันธ์เป็นกระบวนการย้อนกลับของการหาอนุพันธ์ ถ้าอนุพันธ์บอกเราว่าฟังก์ชันเปลี่ยนแปลงอย่างไร แอนตี้อนุพันธ์จะช่วยเราหาฟังก์ชันเดิมจากอัตราการเปลี่ยนแปลงที่ทราบ

1. นิยามของแอนตี้อนุพันธ์

นิยาม: แอนตี้อนุพันธ์

ฟังก์ชัน \(F(x)\) เรียกว่า แอนตี้อนุพันธ์ (antiderivative) ของ \(f(x)\) บนช่วง \(I\) ถ้า

\[F'(x) = f(x) \quad \text{สำหรับทุก } x \text{ ในช่วง } I\]

แนวคิดพื้นฐาน

การหาแอนตี้อนุพันธ์คือการตอบคำถามว่า: "ฟังก์ชันอะไรที่เมื่อหาอนุพันธ์แล้วจะได้ฟังก์ชันที่กำหนดให้?"

\[\text{ถ้า } \frac{d}{dx}[F(x)] = f(x) \text{ แล้ว } F(x) \text{ คือแอนตี้อนุพันธ์ของ } f(x)\]

ตัวอย่าง 1

จงหาแอนตี้อนุพันธ์ของ \(f(x) = 2x\)

วิธีทำ

เราต้องหาฟังก์ชัน \(F(x)\) ที่ \(F'(x) = 2x\)

ลองนึกถึง: ฟังก์ชันอะไรที่เมื่อหาอนุพันธ์แล้วได้ \(2x\)?

เรารู้ว่า:

\[\frac{d}{dx}[x^2] = 2x\]

ดังนั้น \(F(x) = x^2\) คือแอนตี้อนุพันธ์ของ \(f(x) = 2x\)

หมายเหตุ: แต่ \(x^2 + 1\), \(x^2 - 5\), \(x^2 + 100\) ก็เป็นแอนตี้อนุพันธ์ของ \(2x\) ด้วย!
เพราะ \(\frac{d}{dx}[x^2 + C] = 2x\) สำหรับทุกค่าคงที่ \(C\)

ทฤษฎีบท: รูปแบบทั่วไปของแอนตี้อนุพันธ์

ถ้า \(F(x)\) เป็นแอนตี้อนุพันธ์ของ \(f(x)\) บนช่วง \(I\) แล้ว แอนตี้อนุพันธ์ทั่วไปของ \(f(x)\) บนช่วง \(I\) คือ

\[F(x) + C\]

โดยที่ \(C\) เป็นค่าคงที่ใดๆ เรียกว่า ค่าคงที่การอินทิเกรต (constant of integration)

ทำไมต้องมีค่าคงที่ C?

เพราะอนุพันธ์ของค่าคงที่เป็นศูนย์เสมอ:

\[\frac{d}{dx}[C] = 0\]

ดังนั้นถ้า \(F'(x) = f(x)\) แล้ว \((F(x) + C)' = F'(x) + 0 = f(x)\) เช่นกัน

นั่นหมายความว่ามีแอนตี้อนุพันธ์ของฟังก์ชันหนึ่งๆ มากมายนับไม่ถ้วน!

2. กฎพื้นฐานของแอนตี้อนุพันธ์

สูตรแอนตี้อนุพันธ์พื้นฐาน

\(f(x)\) แอนตี้อนุพันธ์ \(F(x) + C\)
\(0\) \(C\)
\(k\) (ค่าคงที่) \(kx + C\)
\(x^n\) (เมื่อ \(n \neq -1\)) \(\displaystyle\frac{x^{n+1}}{n+1} + C\)
\(\displaystyle\frac{1}{x}\) หรือ \(x^{-1}\) \(\ln|x| + C\)
\(e^x\) \(e^x + C\)
\(a^x\) \(\displaystyle\frac{a^x}{\ln a} + C\)

กฎผลรวมและตัวคูณคงที่

ให้ \(F(x)\) เป็นแอนตี้อนุพันธ์ของ \(f(x)\) และ \(G(x)\) เป็นแอนตี้อนุพันธ์ของ \(g(x)\):

  • กฎผลรวม: แอนตี้อนุพันธ์ของ \(f(x) + g(x)\) คือ \(F(x) + G(x) + C\)
  • กฎผลต่าง: แอนตี้อนุพันธ์ของ \(f(x) - g(x)\) คือ \(F(x) - G(x) + C\)
  • กฎตัวคูณคงที่: แอนตี้อนุพันธ์ของ \(kf(x)\) คือ \(kF(x) + C\)

ตัวอย่าง 2

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = x^4\)

วิธีทำ

ใช้สูตร: แอนตี้อนุพันธ์ของ \(x^n\) คือ \(\displaystyle\frac{x^{n+1}}{n+1} + C\)

เมื่อ \(n = 4\):

\[F(x) = \frac{x^{4+1}}{4+1} + C = \frac{x^5}{5} + C\]

ตรวจสอบ:

\[F'(x) = \frac{d}{dx}\left[\frac{x^5}{5} + C\right] = \frac{5x^4}{5} = x^4 = f(x) \quad \checkmark\]

ตัวอย่าง 3

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = 3x^2 - 4x + 5\)

วิธีทำ

ใช้กฎผลรวมและตัวคูณคงที่:

\[F(x) = 3 \cdot \frac{x^3}{3} - 4 \cdot \frac{x^2}{2} + 5x + C\]
\[F(x) = x^3 - 2x^2 + 5x + C\]

ตรวจสอบ:

\[F'(x) = 3x^2 - 4x + 5 = f(x) \quad \checkmark\]

ตัวอย่าง 4

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = \sqrt{x}\)

วิธีทำ

ขั้นที่ 1: เขียนในรูปเลขยกกำลัง

\[f(x) = \sqrt{x} = x^{1/2}\]

ขั้นที่ 2: ใช้สูตร (เมื่อ \(n = \frac{1}{2}\))

\[F(x) = \frac{x^{1/2 + 1}}{1/2 + 1} + C = \frac{x^{3/2}}{3/2} + C = \frac{2}{3}x^{3/2} + C\]

หรือเขียนได้เป็น:

\[F(x) = \frac{2}{3}x\sqrt{x} + C = \frac{2}{3}\sqrt{x^3} + C\]

ตัวอย่าง 5

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(\displaystyle f(x) = \frac{1}{x^3}\)

วิธีทำ

ขั้นที่ 1: เขียนในรูปเลขยกกำลัง

\[f(x) = \frac{1}{x^3} = x^{-3}\]

ขั้นที่ 2: ใช้สูตร (เมื่อ \(n = -3\))

\[F(x) = \frac{x^{-3+1}}{-3+1} + C = \frac{x^{-2}}{-2} + C = -\frac{1}{2x^2} + C\]

ตัวอย่าง 6

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(\displaystyle f(x) = \frac{2x^3 - 5x + 1}{x}\)

วิธีทำ

ขั้นที่ 1: ทำให้เป็นพจน์แยก

\[f(x) = \frac{2x^3}{x} - \frac{5x}{x} + \frac{1}{x} = 2x^2 - 5 + \frac{1}{x}\]

ขั้นที่ 2: หาแอนตี้อนุพันธ์ทีละพจน์

\[F(x) = 2 \cdot \frac{x^3}{3} - 5x + \ln|x| + C\]
\[F(x) = \frac{2x^3}{3} - 5x + \ln|x| + C\]

3. แอนตี้อนุพันธ์ของฟังก์ชันตรีโกณมิติ

สูตรแอนตี้อนุพันธ์ของฟังก์ชันตรีโกณมิติ

\(f(x)\) แอนตี้อนุพันธ์ \(F(x) + C\)
\(\cos x\) \(\sin x + C\)
\(\sin x\) \(-\cos x + C\)
\(\sec^2 x\) \(\tan x + C\)
\(\csc^2 x\) \(-\cot x + C\)
\(\sec x \tan x\) \(\sec x + C\)
\(\csc x \cot x\) \(-\csc x + C\)

ตัวอย่าง 7

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = 3\cos x - 2\sin x\)

วิธีทำ

\[F(x) = 3\sin x - 2(-\cos x) + C = 3\sin x + 2\cos x + C\]

ตรวจสอบ:

\[F'(x) = 3\cos x - 2\sin x = f(x) \quad \checkmark\]

ตัวอย่าง 8

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = \sec x(\sec x + \tan x)\)

วิธีทำ

ขั้นที่ 1: กระจาย

\[f(x) = \sec^2 x + \sec x \tan x\]

ขั้นที่ 2: หาแอนตี้อนุพันธ์ทีละพจน์

\[F(x) = \tan x + \sec x + C\]

4. ปัญหาค่าเริ่มต้น (Initial Value Problems)

แนวคิด

เมื่อเราทราบ เงื่อนไขเริ่มต้น เช่น \(F(a) = b\) เราสามารถหาค่าคงที่ \(C\) เพื่อให้ได้แอนตี้อนุพันธ์เฉพาะที่ผ่านจุดที่กำหนด

ตัวอย่าง 9

จงหาฟังก์ชัน \(F(x)\) ที่ \(F'(x) = 4x - 3\) และ \(F(1) = 5\)

วิธีทำ

ขั้นที่ 1: หาแอนตี้อนุพันธ์ทั่วไป

\[F(x) = 2x^2 - 3x + C\]

ขั้นที่ 2: ใช้เงื่อนไขเริ่มต้น \(F(1) = 5\)

\[F(1) = 2(1)^2 - 3(1) + C = 5\]
\[2 - 3 + C = 5\]
\[C = 6\]

คำตอบ: \(F(x) = 2x^2 - 3x + 6\)

ตัวอย่าง 10

วัตถุเคลื่อนที่ในแนวเส้นตรงโดยมีความเร่ง \(a(t) = 6t\) เมตร/วินาที\(^2\) ถ้าความเร็วเริ่มต้น \(v(0) = 4\) ม./วินาที และตำแหน่งเริ่มต้น \(s(0) = 2\) เมตร จงหาตำแหน่ง \(s(t)\)

วิธีทำ

ขั้นที่ 1: หาความเร็วจากความเร่ง

เรารู้ว่า \(v'(t) = a(t) = 6t\)

\[v(t) = 3t^2 + C_1\]

ใช้เงื่อนไข \(v(0) = 4\):

\[v(0) = 3(0)^2 + C_1 = 4 \Rightarrow C_1 = 4\]
\[v(t) = 3t^2 + 4\]

ขั้นที่ 2: หาตำแหน่งจากความเร็ว

เรารู้ว่า \(s'(t) = v(t) = 3t^2 + 4\)

\[s(t) = t^3 + 4t + C_2\]

ใช้เงื่อนไข \(s(0) = 2\):

\[s(0) = 0 + 0 + C_2 = 2 \Rightarrow C_2 = 2\]

คำตอบ: \(s(t) = t^3 + 4t + 2\) เมตร

ตัวอย่าง 11

จงหาฟังก์ชัน \(f(x)\) โดยที่ \(f''(x) = 12x - 6\), \(f'(0) = 1\) และ \(f(0) = 3\)

วิธีทำ

ขั้นที่ 1: หา \(f'(x)\) จาก \(f''(x)\)

\[f'(x) = 6x^2 - 6x + C_1\]

ใช้ \(f'(0) = 1\):

\[f'(0) = 0 - 0 + C_1 = 1 \Rightarrow C_1 = 1\]
\[f'(x) = 6x^2 - 6x + 1\]

ขั้นที่ 2: หา \(f(x)\) จาก \(f'(x)\)

\[f(x) = 2x^3 - 3x^2 + x + C_2\]

ใช้ \(f(0) = 3\):

\[f(0) = 0 - 0 + 0 + C_2 = 3 \Rightarrow C_2 = 3\]

คำตอบ: \(f(x) = 2x^3 - 3x^2 + x + 3\)

สรุป

สิ่งที่ควรจำ

  • \(F(x)\) เป็นแอนตี้อนุพันธ์ของ \(f(x)\) ถ้า \(F'(x) = f(x)\)
  • แอนตี้อนุพันธ์ทั่วไป = \(F(x) + C\) (ต้องมีค่าคงที่ \(C\) เสมอ)
  • สูตรหลัก: \(\displaystyle\int x^n \, dx = \frac{x^{n+1}}{n+1} + C\) เมื่อ \(n \neq -1\)
  • สำหรับ \(n = -1\): \(\displaystyle\int \frac{1}{x} \, dx = \ln|x| + C\)
  • ปัญหาค่าเริ่มต้น: ใช้เงื่อนไขที่กำหนดเพื่อหาค่า \(C\)

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = 5x^4 - 3x^2 + 2\)

\[F(x) = 5 \cdot \frac{x^5}{5} - 3 \cdot \frac{x^3}{3} + 2x + C = x^5 - x^3 + 2x + C\]

แบบฝึกหัดที่ 2

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(\displaystyle f(x) = \frac{3}{\sqrt{x}}\)

\(\displaystyle f(x) = 3x^{-1/2}\)

\[F(x) = 3 \cdot \frac{x^{1/2}}{1/2} + C = 6\sqrt{x} + C\]

แบบฝึกหัดที่ 3

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(f(x) = 2\sin x + 5\cos x\)

\[F(x) = -2\cos x + 5\sin x + C\]

แบบฝึกหัดที่ 4

จงหาแอนตี้อนุพันธ์ทั่วไปของ \(\displaystyle f(x) = \frac{x^4 + 2x^2 - 1}{x^2}\)

ทำให้เป็นพจน์แยก: \(f(x) = x^2 + 2 - x^{-2}\)

\[F(x) = \frac{x^3}{3} + 2x + \frac{1}{x} + C\]

แบบฝึกหัดที่ 5

จงหา \(F(x)\) ที่ \(F'(x) = x^2 - 4x + 3\) และ \(F(2) = 1\)

แอนตี้อนุพันธ์ทั่วไป: \(\displaystyle F(x) = \frac{x^3}{3} - 2x^2 + 3x + C\)

ใช้ \(F(2) = 1\):

\[\frac{8}{3} - 8 + 6 + C = 1\]
\[\frac{8}{3} - 2 + C = 1 \Rightarrow C = 1 - \frac{8}{3} + 2 = 3 - \frac{8}{3} = \frac{1}{3}\]
\[F(x) = \frac{x^3}{3} - 2x^2 + 3x + \frac{1}{3}\]

แบบฝึกหัดที่ 6

วัตถุตกอิสระจากที่สูง โดยมีความเร่ง \(a(t) = -10\) ม./วินาที\(^2\) ถ้า \(v(0) = 0\) และ \(s(0) = 100\) ม. จงหา \(s(t)\) และเวลาที่วัตถุตกถึงพื้น

\(v(t) = -10t + C_1\), ใช้ \(v(0) = 0\): \(C_1 = 0\)

\(v(t) = -10t\)

\(s(t) = -5t^2 + C_2\), ใช้ \(s(0) = 100\): \(C_2 = 100\)

\[s(t) = -5t^2 + 100\]

ตกถึงพื้นเมื่อ \(s(t) = 0\):

\[-5t^2 + 100 = 0 \Rightarrow t^2 = 20 \Rightarrow t = \sqrt{20} = 2\sqrt{5} \approx 4.47 \text{ วินาที}\]
