4.2 อินทิกรัลไม่จำกัดเขต (Indefinite Integrals)

อินทิกรัลไม่จำกัดเขตคือสัญลักษณ์มาตรฐานสำหรับการหาแอนตี้อนุพันธ์ ในบทนี้เราจะเรียนรู้สัญกรณ์อินทิกรัลและสูตรพื้นฐานที่จำเป็น

1. สัญกรณ์อินทิกรัล (Integral Notation)

นิยาม: อินทิกรัลไม่จำกัดเขต

อินทิกรัลไม่จำกัดเขต (Indefinite Integral) ของ \(f(x)\) เขียนแทนด้วย:

\[\int f(x) \, dx = F(x) + C\]

โดยที่ \(F(x)\) คือแอนตี้อนุพันธ์ของ \(f(x)\) และ \(C\) คือค่าคงที่

ส่วนประกอบของสัญลักษณ์

  • \(\int\) - เครื่องหมายอินทิกรัล (integral sign)
  • \(f(x)\) - ฟังก์ชันที่จะอินทิเกรต เรียกว่า integrand
  • \(dx\) - ดิฟเฟอเรนเชียล แสดงว่าตัวแปรคือ \(x\)
  • \(C\) - ค่าคงที่การอินทิเกรต (constant of integration)

ข้อควรจำ

การหาอนุพันธ์และการอินทิเกรตเป็นกระบวนการตรงข้ามกัน:

\[\frac{d}{dx}\left[\int f(x) \, dx\right] = f(x)\]
\[\int F'(x) \, dx = F(x) + C\]

2. สูตรอินทิกรัลพื้นฐาน

สูตรอินทิกรัลพื้นฐาน

สูตร เงื่อนไข
\(\displaystyle\int k \, dx = kx + C\) \(k\) เป็นค่าคงที่
\(\displaystyle\int x^n \, dx = \frac{x^{n+1}}{n+1} + C\) \(n \neq -1\)
\(\displaystyle\int \frac{1}{x} \, dx = \ln|x| + C\) \(x \neq 0\)
\(\displaystyle\int e^x \, dx = e^x + C\)
\(\displaystyle\int a^x \, dx = \frac{a^x}{\ln a} + C\) \(a > 0, a \neq 1\)

สูตรอินทิกรัลตรีโกณมิติ

สูตร
\(\displaystyle\int \cos x \, dx = \sin x + C\)
\(\displaystyle\int \sin x \, dx = -\cos x + C\)
\(\displaystyle\int \sec^2 x \, dx = \tan x + C\)
\(\displaystyle\int \csc^2 x \, dx = -\cot x + C\)
\(\displaystyle\int \sec x \tan x \, dx = \sec x + C\)
\(\displaystyle\int \csc x \cot x \, dx = -\csc x + C\)
\(\displaystyle\int \tan x \, dx = -\ln|\cos x| + C = \ln|\sec x| + C\)
\(\displaystyle\int \cot x \, dx = \ln|\sin x| + C\)
\(\displaystyle\int \sec x \, dx = \ln|\sec x + \tan x| + C\)
\(\displaystyle\int \csc x \, dx = -\ln|\csc x + \cot x| + C\)

สมบัติของอินทิกรัล

  • ตัวคูณคงที่: \(\displaystyle\int kf(x) \, dx = k\int f(x) \, dx\)
  • ผลรวม: \(\displaystyle\int [f(x) + g(x)] \, dx = \int f(x) \, dx + \int g(x) \, dx\)
  • ผลต่าง: \(\displaystyle\int [f(x) - g(x)] \, dx = \int f(x) \, dx - \int g(x) \, dx\)

3. ตัวอย่างการคำนวณ

ตัวอย่าง 1

จงหา \(\displaystyle\int (3x^2 + 4x - 5) \, dx\)

วิธีทำ

ใช้กฎผลรวมและสูตรพื้นฐาน:

\[\int (3x^2 + 4x - 5) \, dx = 3\int x^2 \, dx + 4\int x \, dx - 5\int dx\]
\[= 3 \cdot \frac{x^3}{3} + 4 \cdot \frac{x^2}{2} - 5x + C\]
\[= x^3 + 2x^2 - 5x + C\]

ตัวอย่าง 2

จงหา \(\displaystyle\int \left(x^3 - \frac{2}{x} + 3e^x\right) dx\)

วิธีทำ

\[\int \left(x^3 - \frac{2}{x} + 3e^x\right) dx = \int x^3 \, dx - 2\int \frac{1}{x} \, dx + 3\int e^x \, dx\]
\[= \frac{x^4}{4} - 2\ln|x| + 3e^x + C\]

ตัวอย่าง 3

จงหา \(\displaystyle\int \frac{x^2 + 3x - 2}{x} \, dx\)

วิธีทำ

ขั้นที่ 1: แยกเศษส่วน

\[\frac{x^2 + 3x - 2}{x} = x + 3 - \frac{2}{x}\]

ขั้นที่ 2: อินทิเกรตทีละพจน์

\[\int \left(x + 3 - \frac{2}{x}\right) dx = \frac{x^2}{2} + 3x - 2\ln|x| + C\]

ตัวอย่าง 4

จงหา \(\displaystyle\int (\sqrt{x} + \sqrt[3]{x^2}) \, dx\)

วิธีทำ

ขั้นที่ 1: เขียนในรูปเลขยกกำลัง

\[\sqrt{x} = x^{1/2}, \quad \sqrt[3]{x^2} = x^{2/3}\]

ขั้นที่ 2: อินทิเกรต

\[\int (x^{1/2} + x^{2/3}) \, dx = \frac{x^{3/2}}{3/2} + \frac{x^{5/3}}{5/3} + C\]
\[= \frac{2}{3}x^{3/2} + \frac{3}{5}x^{5/3} + C\]
\[= \frac{2}{3}x\sqrt{x} + \frac{3}{5}\sqrt[3]{x^5} + C\]

ตัวอย่าง 5

จงหา \(\displaystyle\int (2\sin x - 3\cos x + \sec^2 x) \, dx\)

วิธีทำ

\[\int (2\sin x - 3\cos x + \sec^2 x) \, dx\]
\[= 2(-\cos x) - 3(\sin x) + \tan x + C\]
\[= -2\cos x - 3\sin x + \tan x + C\]

ตัวอย่าง 6

จงหา \(\displaystyle\int \frac{1 + \cos^2 x}{\cos^2 x} \, dx\)

วิธีทำ

ขั้นที่ 1: แยกเศษส่วน

\[\frac{1 + \cos^2 x}{\cos^2 x} = \frac{1}{\cos^2 x} + 1 = \sec^2 x + 1\]

ขั้นที่ 2: อินทิเกรต

\[\int (\sec^2 x + 1) \, dx = \tan x + x + C\]

ตัวอย่าง 7

จงหา \(\displaystyle\int (x + 1)^2 \, dx\)

วิธีทำ

วิธีที่ 1: กระจายก่อน

\[(x + 1)^2 = x^2 + 2x + 1\]
\[\int (x^2 + 2x + 1) \, dx = \frac{x^3}{3} + x^2 + x + C\]

วิธีที่ 2: ใช้สูตร \(\int u^n \, du = \frac{u^{n+1}}{n+1} + C\)

ให้ \(u = x + 1\), \(du = dx\)

\[\int (x + 1)^2 \, dx = \frac{(x + 1)^3}{3} + C\]
หมายเหตุ: ทั้งสองคำตอบเท่ากัน!
\(\displaystyle\frac{(x+1)^3}{3} = \frac{x^3 + 3x^2 + 3x + 1}{3} = \frac{x^3}{3} + x^2 + x + \frac{1}{3}\)
ต่างกันแค่ค่าคงที่ ซึ่งรวมอยู่ใน \(C\) ได้

4. บทนำการแทนค่า (Introduction to Substitution)

แนวคิดการแทนค่า

เมื่ออินทิกรัลมีรูปแบบ \(\displaystyle\int f(g(x)) \cdot g'(x) \, dx\) เราสามารถใช้วิธีการแทนค่า (u-substitution) เพื่อทำให้อินทิกรัลง่ายขึ้น

\[\text{ให้ } u = g(x), \quad du = g'(x) \, dx\]
\[\int f(g(x)) \cdot g'(x) \, dx = \int f(u) \, du\]

ตัวอย่าง 8

จงหา \(\displaystyle\int 2x(x^2 + 1)^4 \, dx\)

วิธีทำ

ขั้นที่ 1: กำหนด \(u\)

ให้ \(u = x^2 + 1\), \(du = 2x \, dx\)

ขั้นที่ 2: แทนค่า

\[\int 2x(x^2 + 1)^4 \, dx = \int u^4 \, du\]

ขั้นที่ 3: อินทิเกรต

\[\int u^4 \, du = \frac{u^5}{5} + C\]

ขั้นที่ 4: แทนค่ากลับ

\[= \frac{(x^2 + 1)^5}{5} + C\]

ตัวอย่าง 9

จงหา \(\displaystyle\int \cos(3x) \, dx\)

วิธีทำ

ให้ \(u = 3x\), \(du = 3 \, dx\), ดังนั้น \(dx = \frac{du}{3}\)

\[\int \cos(3x) \, dx = \int \cos u \cdot \frac{du}{3} = \frac{1}{3}\int \cos u \, du\]
\[= \frac{1}{3}\sin u + C = \frac{1}{3}\sin(3x) + C\]

ตัวอย่าง 10

จงหา \(\displaystyle\int \frac{x}{x^2 + 1} \, dx\)

วิธีทำ

ให้ \(u = x^2 + 1\), \(du = 2x \, dx\), ดังนั้น \(x \, dx = \frac{du}{2}\)

\[\int \frac{x}{x^2 + 1} \, dx = \int \frac{1}{u} \cdot \frac{du}{2} = \frac{1}{2}\int \frac{1}{u} \, du\]
\[= \frac{1}{2}\ln|u| + C = \frac{1}{2}\ln(x^2 + 1) + C\]

หมายเหตุ: ไม่ต้องใส่ค่าสัมบูรณ์เพราะ \(x^2 + 1 > 0\) เสมอ

ตัวอย่าง 11

จงหา \(\displaystyle\int e^{5x} \, dx\)

วิธีทำ

ให้ \(u = 5x\), \(du = 5 \, dx\), ดังนั้น \(dx = \frac{du}{5}\)

\[\int e^{5x} \, dx = \int e^u \cdot \frac{du}{5} = \frac{1}{5}e^u + C = \frac{1}{5}e^{5x} + C\]

5. รูปแบบที่พบบ่อย

สูตรสำหรับฟังก์ชันเชิงเส้นภายใน

ถ้า \(a \neq 0\):

อินทิกรัล ผลลัพธ์
\(\displaystyle\int (ax + b)^n \, dx\) \(\displaystyle\frac{(ax + b)^{n+1}}{a(n+1)} + C\) เมื่อ \(n \neq -1\)
\(\displaystyle\int \frac{1}{ax + b} \, dx\) \(\displaystyle\frac{1}{a}\ln|ax + b| + C\)
\(\displaystyle\int e^{ax + b} \, dx\) \(\displaystyle\frac{1}{a}e^{ax + b} + C\)
\(\displaystyle\int \sin(ax + b) \, dx\) \(\displaystyle-\frac{1}{a}\cos(ax + b) + C\)
\(\displaystyle\int \cos(ax + b) \, dx\) \(\displaystyle\frac{1}{a}\sin(ax + b) + C\)

สรุป

ประเด็นสำคัญ

  • \(\displaystyle\int f(x) \, dx = F(x) + C\) โดยที่ \(F'(x) = f(x)\)
  • อย่าลืม \(+C\) ทุกครั้งสำหรับอินทิกรัลไม่จำกัดเขต
  • ตรวจสอบคำตอบได้โดยการหาอนุพันธ์
  • การแทนค่าช่วยให้อินทิกรัลซับซ้อนง่ายขึ้น
  • สำหรับ \(\int f(ax + b) \, dx\) ต้องหารด้วย \(a\)

แบบฝึกหัด

แบบฝึกหัดที่ 1

จงหา \(\displaystyle\int (4x^3 - 2x^2 + 7) \, dx\)

\[\int (4x^3 - 2x^2 + 7) \, dx = x^4 - \frac{2x^3}{3} + 7x + C\]

แบบฝึกหัดที่ 2

จงหา \(\displaystyle\int \left(\frac{1}{x^2} + \frac{1}{x^3}\right) dx\)

\[\int (x^{-2} + x^{-3}) \, dx = -x^{-1} - \frac{x^{-2}}{2} + C = -\frac{1}{x} - \frac{1}{2x^2} + C\]

แบบฝึกหัดที่ 3

จงหา \(\displaystyle\int (\sin x + \cos x)^2 \, dx\)

กระจาย: \((\sin x + \cos x)^2 = \sin^2 x + 2\sin x\cos x + \cos^2 x = 1 + \sin 2x\)

\[\int (1 + \sin 2x) \, dx = x - \frac{1}{2}\cos 2x + C\]

แบบฝึกหัดที่ 4

จงหา \(\displaystyle\int 3x^2 e^{x^3} \, dx\)

ให้ \(u = x^3\), \(du = 3x^2 \, dx\)

\[\int 3x^2 e^{x^3} \, dx = \int e^u \, du = e^u + C = e^{x^3} + C\]

แบบฝึกหัดที่ 5

จงหา \(\displaystyle\int \frac{1}{2x - 3} \, dx\)

ใช้สูตร \(\displaystyle\int \frac{1}{ax + b} \, dx = \frac{1}{a}\ln|ax + b| + C\)

\[\int \frac{1}{2x - 3} \, dx = \frac{1}{2}\ln|2x - 3| + C\]

แบบฝึกหัดที่ 6

จงหา \(\displaystyle\int (3x + 2)^5 \, dx\)

ใช้สูตร หรือให้ \(u = 3x + 2\), \(du = 3 \, dx\)

\[\int (3x + 2)^5 \, dx = \frac{(3x + 2)^6}{3 \cdot 6} + C = \frac{(3x + 2)^6}{18} + C\]

แบบฝึกหัดที่ 7

จงหา \(\displaystyle\int \cos x \sin^3 x \, dx\)

ให้ \(u = \sin x\), \(du = \cos x \, dx\)

\[\int \cos x \sin^3 x \, dx = \int u^3 \, du = \frac{u^4}{4} + C = \frac{\sin^4 x}{4} + C\]
