3.3 ค่าสูงสุดและต่ำสุด (Extrema)

📖

ทฤษฎีและแนวคิด

1. นิยาม

ค่าสูงสุด/ต่ำสุดสัมพัทธ์ (Local/Relative Extrema)

  • $f(c)$ เป็นค่าสูงสุดสัมพัทธ์ ถ้า $f(c) \geq f(x)$ สำหรับทุก $x$ ในบริเวณใกล้เคียง $c$
  • $f(c)$ เป็นค่าต่ำสุดสัมพัทธ์ ถ้า $f(c) \leq f(x)$ สำหรับทุก $x$ ในบริเวณใกล้เคียง $c$

ค่าสูงสุด/ต่ำสุดสัมบูรณ์ (Absolute/Global Extrema)

  • $f(c)$ เป็นค่าสูงสุดสัมบูรณ์ ถ้า $f(c) \geq f(x)$ สำหรับทุก $x$ ในโดเมน
  • $f(c)$ เป็นค่าต่ำสุดสัมบูรณ์ ถ้า $f(c) \leq f(x)$ สำหรับทุก $x$ ในโดเมน

2. First Derivative Test

First Derivative Test

ให้ $c$ เป็นจุดวิกฤต (คือ $f'(c) = 0$ หรือไม่มีนิยาม):

  • ถ้า $f'$ เปลี่ยนจาก $+$ เป็น $-$ ที่ $c$ → $f(c)$ เป็นค่าสูงสุดสัมพัทธ์
  • ถ้า $f'$ เปลี่ยนจาก $-$ เป็น $+$ ที่ $c$ → $f(c)$ เป็นค่าต่ำสุดสัมพัทธ์
  • ถ้า $f'$ ไม่เปลี่ยนเครื่องหมาย → ไม่ใช่ค่าสูงสุดหรือต่ำสุด

3. Second Derivative Test

Second Derivative Test

ให้ $c$ เป็นจุดวิกฤตที่ $f'(c) = 0$:

  • ถ้า $f''(c) < 0$ → $f(c)$ เป็นค่าสูงสุดสัมพัทธ์
  • ถ้า $f''(c) > 0$ → $f(c)$ เป็นค่าต่ำสุดสัมพัทธ์
  • ถ้า $f''(c) = 0$ → ไม่สามารถสรุปได้ (ต้องใช้ First Derivative Test)

4. การหาค่าสูงสุด/ต่ำสุดบนช่วงปิด

Closed Interval Method

หาค่าสูงสุด/ต่ำสุดสัมบูรณ์ของ $f$ บน $[a, b]$:

  1. หาจุดวิกฤตทั้งหมดใน $(a, b)$
  2. หาค่า $f$ ที่จุดวิกฤตทั้งหมดและที่จุดปลาย $a$, $b$
  3. ค่าที่มากที่สุดคือค่าสูงสุดสัมบูรณ์ ค่าที่น้อยที่สุดคือค่าต่ำสุดสัมบูรณ์

5. ปัญหา Optimization

ขั้นตอนแก้ปัญหา Optimization
  1. อ่านโจทย์และเข้าใจสิ่งที่ต้องการ maximize/minimize
  2. วาดรูปและกำหนดตัวแปร
  3. เขียนฟังก์ชันที่ต้องการ optimize
  4. เขียนเงื่อนไข (constraints) และใช้ลดจำนวนตัวแปร
  5. หาอนุพันธ์และแก้สมการ $f'(x) = 0$
  6. ตรวจสอบว่าเป็นค่าสูงสุดหรือต่ำสุด
💡

ตัวอย่าง

ตัวอย่างที่ 1 ปานกลาง

โจทย์:

หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^3 - 3x + 1$ บนช่วง $[-2, 2]$

วิธีทำ:

ขั้นตอนที่ 1: หาจุดวิกฤต
$$f'(x) = 3x^2 - 3 = 3(x^2 - 1) = 3(x-1)(x+1) = 0$$

จุดวิกฤต: $x = -1$ และ $x = 1$ (ทั้งคู่อยู่ในช่วง)

ขั้นตอนที่ 2: หาค่าฟังก์ชัน
$$\begin{align} f(-2) &= -8 + 6 + 1 = -1\\ f(-1) &= -1 + 3 + 1 = 3\\ f(1) &= 1 - 3 + 1 = -1\\ f(2) &= 8 - 6 + 1 = 3 \end{align}$$
คำตอบ:

ค่าสูงสุดสัมบูรณ์ = 3 ที่ $x = -1$ และ $x = 2$

ค่าต่ำสุดสัมบูรณ์ = -1 ที่ $x = -2$ และ $x = 1$

ตัวอย่างที่ 2 ปานกลาง

โจทย์:

หาค่าสูงสุดและต่ำสุดสัมพัทธ์ของ $f(x) = 2x^3 - 9x^2 + 12x - 3$ โดยใช้ Second Derivative Test

วิธีทำ:

ขั้นตอนที่ 1: หาจุดวิกฤต
$$f'(x) = 6x^2 - 18x + 12 = 6(x^2 - 3x + 2) = 6(x-1)(x-2) = 0$$

จุดวิกฤต: $x = 1$ และ $x = 2$

ขั้นตอนที่ 2: ใช้ Second Derivative Test
$$f''(x) = 12x - 18$$

$f''(1) = 12 - 18 = -6 < 0$ → ค่าสูงสุดสัมพัทธ์

$f''(2) = 24 - 18 = 6 > 0$ → ค่าต่ำสุดสัมพัทธ์

ขั้นตอนที่ 3: หาค่า
$$f(1) = 2 - 9 + 12 - 3 = 2$$
$$f(2) = 16 - 36 + 24 - 3 = 1$$
คำตอบ:

ค่าสูงสุดสัมพัทธ์ = 2 ที่ $x = 1$

ค่าต่ำสุดสัมพัทธ์ = 1 ที่ $x = 2$

ตัวอย่างที่ 3 ท้าทาย

โจทย์ (Optimization):

ต้องการสร้างกล่องไม่มีฝาจากแผ่นโลหะสี่เหลี่ยมจัตุรัสขนาด 12 ซม. x 12 ซม. โดยตัดมุมเป็นสี่เหลี่ยมจัตุรัสเท่าๆ กัน แล้วพับขึ้น จะต้องตัดมุมขนาดเท่าไรจึงจะได้กล่องที่มีปริมาตรมากที่สุด?

วิธีทำ:

ขั้นตอนที่ 1: กำหนดตัวแปร

ให้ $x$ = ความยาวด้านของสี่เหลี่ยมที่ตัดมุม

ขนาดกล่อง: $(12-2x) \times (12-2x) \times x$

เงื่อนไข: $0 < x < 6$

ขั้นตอนที่ 2: เขียนฟังก์ชันปริมาตร
$$V(x) = x(12-2x)^2 = x(144 - 48x + 4x^2) = 4x^3 - 48x^2 + 144x$$
ขั้นตอนที่ 3: หาจุดวิกฤต
$$V'(x) = 12x^2 - 96x + 144 = 12(x^2 - 8x + 12) = 12(x-2)(x-6) = 0$$

$x = 2$ หรือ $x = 6$ แต่ $x = 6$ ไม่อยู่ในเงื่อนไข

ขั้นตอนที่ 4: ตรวจสอบ
$$V''(x) = 24x - 96, \quad V''(2) = 48 - 96 = -48 < 0$$

ดังนั้น $x = 2$ ให้ค่าสูงสุด

$$V(2) = 2(12-4)^2 = 2(64) = 128 \text{ cm}^3$$
คำตอบ:

ตัดมุมขนาด 2 ซม. x 2 ซม. จะได้ปริมาตรมากที่สุด 128 ลูกบาศก์เซนติเมตร

✍️

แบบฝึกหัด

ระดับพื้นฐาน

ข้อ 1:

หาค่าสูงสุดและต่ำสุดสัมบูรณ์ของ $f(x) = x^2 - 4x + 5$ บนช่วง $[0, 4]$

เฉลย:

$f'(x) = 2x - 4 = 0 \Rightarrow x = 2$

$f(0) = 5$, $f(2) = 1$, $f(4) = 5$

คำตอบ: สูงสุด = 5 ที่ $x = 0, 4$, ต่ำสุด = 1 ที่ $x = 2$

ข้อ 2:

หาค่าสูงสุดและต่ำสุดสัมพัทธ์ของ $f(x) = x^3 - 12x$

เฉลย:

$f'(x) = 3x^2 - 12 = 0 \Rightarrow x = \pm 2$

$f''(x) = 6x$

$f''(-2) = -12 < 0$ → สูงสุดสัมพัทธ์ที่ $(-2, 16)$

$f''(2) = 12 > 0$ → ต่ำสุดสัมพัทธ์ที่ $(2, -16)$

ระดับท้าทาย

ข้อ 3:

หาจำนวนบวกสองจำนวนที่มีผลบวกเท่ากับ 20 และมีผลคูณมากที่สุด

เฉลย:

ให้ $x$ และ $20-x$ เป็นจำนวนสองจำนวน

$P(x) = x(20-x) = 20x - x^2$

$P'(x) = 20 - 2x = 0 \Rightarrow x = 10$

คำตอบ: จำนวนทั้งสองคือ 10 และ 10 (ผลคูณ = 100)
