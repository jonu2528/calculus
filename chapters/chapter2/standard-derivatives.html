หน้าแรก บทที่ 2: อนุพันธ์ 2.3 อนุพันธ์ของฟังก์ชันมาตรฐาน

2.3 อนุพันธ์ของฟังก์ชันมาตรฐาน (Derivatives of Standard Functions)

📖

ทฤษฎีและแนวคิด

นอกจากฟังก์ชันพหุนามแล้ว เรายังต้องรู้วิธีหาอนุพันธ์ของฟังก์ชันมาตรฐานอื่นๆ ที่สำคัญ

1. ฟังก์ชันเลขชี้กำลัง (Exponential Functions)

อนุพันธ์ของ $e^x$

นี่คือคุณสมบัติพิเศษที่สำคัญมากของ $e$:

$$\frac{d}{dx}(e^x) = e^x$$

ฟังก์ชัน $e^x$ เป็นฟังก์ชันเดียวที่อนุพันธ์เท่ากับตัวมันเอง!

อนุพันธ์ของ $a^x$ (ฐานอื่น)

$$\frac{d}{dx}(a^x) = a^x \ln a$$

โดยที่ $a > 0$ และ $a \neq 1$

ข้อสังเกต

เมื่อ $a = e$ จะได้ $\frac{d}{dx}(e^x) = e^x \ln e = e^x \cdot 1 = e^x$ ซึ่งสอดคล้องกับสูตรข้างบน

ร่วมกับ Chain Rule

ถ้า $u = g(x)$ แล้ว:

$$\frac{d}{dx}(e^u) = e^u \cdot \frac{du}{dx}$$

ตัวอย่าง: $\frac{d}{dx}(e^{3x}) = e^{3x} \cdot 3 = 3e^{3x}$

2. ฟังก์ชันลอการิทึม (Logarithmic Functions)

อนุพันธ์ของ $\ln x$

$$\frac{d}{dx}(\ln x) = \frac{1}{x}, \quad x > 0$$

อนุพันธ์ของ $\log_a x$

$$\frac{d}{dx}(\log_a x) = \frac{1}{x \ln a}, \quad x > 0$$

ร่วมกับ Chain Rule

ถ้า $u = g(x)$ แล้ว:

$$\frac{d}{dx}(\ln u) = \frac{1}{u} \cdot \frac{du}{dx} = \frac{u'}{u}$$

ตัวอย่าง: $\frac{d}{dx}(\ln(x^2 + 1)) = \frac{1}{x^2 + 1} \cdot 2x = \frac{2x}{x^2 + 1}$

เทคนิค: Logarithmic Differentiation

สำหรับฟังก์ชันที่ซับซ้อน เช่น $y = x^x$ หรือผลคูณหลายตัว สามารถใช้ ln ทั้งสองข้างก่อนหาอนุพันธ์

3. ฟังก์ชันตรีโกณมิติ (Trigonometric Functions)

อนุพันธ์พื้นฐาน

$$\begin{align} \frac{d}{dx}(\sin x) &= \cos x\\ \frac{d}{dx}(\cos x) &= -\sin x\\ \frac{d}{dx}(\tan x) &= \sec^2 x\\ \frac{d}{dx}(\cot x) &= -\csc^2 x\\ \frac{d}{dx}(\sec x) &= \sec x \tan x\\ \frac{d}{dx}(\csc x) &= -\csc x \cot x \end{align}$$
วิธีจำ
  • ฟังก์ชันที่มี "co-" ข้างหน้า (cos, cot, csc) จะมีเครื่องหมายลบ
  • $\sin$ และ $\cos$ สลับกัน: $\sin \to \cos$ และ $\cos \to -\sin$
  • $\tan$ และ $\sec$ อยู่ด้วยกัน: $\frac{d}{dx}(\tan x) = \sec^2 x$ และ $\frac{d}{dx}(\sec x) = \sec x \tan x$

ร่วมกับ Chain Rule

ตัวอย่าง:

  • $\frac{d}{dx}(\sin(3x)) = \cos(3x) \cdot 3 = 3\cos(3x)$
  • $\frac{d}{dx}(\cos(x^2)) = -\sin(x^2) \cdot 2x = -2x\sin(x^2)$
  • $\frac{d}{dx}(\tan(2x+1)) = \sec^2(2x+1) \cdot 2 = 2\sec^2(2x+1)$

4. ฟังก์ชันตรีโกณมิติผกผัน (Inverse Trigonometric Functions)

$$\begin{align} \frac{d}{dx}(\arcsin x) &= \frac{1}{\sqrt{1-x^2}}, \quad -1 < x < 1\\ \frac{d}{dx}(\arccos x) &= -\frac{1}{\sqrt{1-x^2}}, \quad -1 < x < 1\\ \frac{d}{dx}(\arctan x) &= \frac{1}{1+x^2}\\ \frac{d}{dx}(\text{arccot } x) &= -\frac{1}{1+x^2}\\ \frac{d}{dx}(\text{arcsec } x) &= \frac{1}{|x|\sqrt{x^2-1}}, \quad |x| > 1\\ \frac{d}{dx}(\text{arccsc } x) &= -\frac{1}{|x|\sqrt{x^2-1}}, \quad |x| > 1 \end{align}$$
หมายเหตุ

ฟังก์ชัน $\arcsin x$ เหมือนกับ $\sin^{-1} x$ (ไม่ใช่ $\frac{1}{\sin x}$)

สังเกตว่าฟังก์ชันที่มี "arc-co" จะมีเครื่องหมายลบ

ข้อควรระวัง

อนุพันธ์ของฟังก์ชัน trig ต้องใช้มุมในหน่วยเรเดียน (radian) ไม่ใช่องศา!

💡

ตัวอย่าง

ตัวอย่างที่ 1 ง่าย

โจทย์:

หาอนุพันธ์ของฟังก์ชันต่อไปนี้:

ก) $f(x) = 3e^x + 2^x$

ข) $g(x) = \ln x + \log_{10} x$

วิธีทำ:

ก) ใช้สูตรฟังก์ชันเลขชี้กำลัง
$$\begin{align} f'(x) &= 3 \cdot \frac{d}{dx}(e^x) + \frac{d}{dx}(2^x)\\ &= 3e^x + 2^x \ln 2 \end{align}$$
ข) ใช้สูตรฟังก์ชันลอการิทึม
$$\begin{align} g'(x) &= \frac{d}{dx}(\ln x) + \frac{d}{dx}(\log_{10} x)\\ &= \frac{1}{x} + \frac{1}{x \ln 10}\\ &= \frac{1}{x}\left(1 + \frac{1}{\ln 10}\right) \end{align}$$
คำตอบ:

ก) $f'(x) = 3e^x + 2^x \ln 2$

ข) $g'(x) = \frac{1}{x} + \frac{1}{x\ln 10}$

ตัวอย่างที่ 2 ง่าย

โจทย์:

หาอนุพันธ์ของ $h(x) = \sin x + \cos x - \tan x$

วิธีทำ:

ใช้สูตรฟังก์ชันตรีโกณมิติ
$$\begin{align} h'(x) &= \frac{d}{dx}(\sin x) + \frac{d}{dx}(\cos x) - \frac{d}{dx}(\tan x)\\ &= \cos x + (-\sin x) - \sec^2 x\\ &= \cos x - \sin x - \sec^2 x \end{align}$$
คำตอบ:

$h'(x) = \cos x - \sin x - \sec^2 x$

ตัวอย่างที่ 3 ปานกลาง

โจทย์:

หาอนุพันธ์ของ $f(x) = e^{2x^2 + 3x}$ โดยใช้ Chain Rule

วิธีทำ:

ขั้นตอนที่ 1: ระบุฟังก์ชันนอกและใน

ฟังก์ชันนอก: $e^u$ มีอนุพันธ์ $e^u$

ฟังก์ชันใน: $u = 2x^2 + 3x$ มีอนุพันธ์ $4x + 3$

ขั้นตอนที่ 2: ใช้ Chain Rule
$$\begin{align} f'(x) &= e^{2x^2 + 3x} \cdot \frac{d}{dx}(2x^2 + 3x)\\ &= e^{2x^2 + 3x} \cdot (4x + 3)\\ &= (4x + 3)e^{2x^2 + 3x} \end{align}$$
คำตอบ:

$f'(x) = (4x + 3)e^{2x^2 + 3x}$

ตัวอย่างที่ 4 ปานกลาง

โจทย์:

หาอนุพันธ์ของ $g(x) = \ln(x^3 - 2x + 5)$

วิธีทำ:

ใช้ Chain Rule กับ ln

ให้ $u = x^3 - 2x + 5$ แล้ว $u' = 3x^2 - 2$

$$\begin{align} g'(x) &= \frac{1}{x^3 - 2x + 5} \cdot (3x^2 - 2)\\ &= \frac{3x^2 - 2}{x^3 - 2x + 5} \end{align}$$
คำตอบ:

$g'(x) = \frac{3x^2 - 2}{x^3 - 2x + 5}$

ตัวอย่างที่ 5 ปานกลาง

โจทย์:

หาอนุพันธ์ของ $y = \sin(3x^2) \cos(5x)$ โดยใช้ Product Rule และ Chain Rule

วิธีทำ:

ขั้นตอนที่ 1: ใช้ Product Rule

ให้ $u = \sin(3x^2)$ และ $v = \cos(5x)$

ต้องหา $u'$ และ $v'$ ด้วย Chain Rule

ขั้นตอนที่ 2: หา $u'$ ด้วย Chain Rule
$$u' = \cos(3x^2) \cdot 6x = 6x\cos(3x^2)$$
ขั้นตอนที่ 3: หา $v'$ ด้วย Chain Rule
$$v' = -\sin(5x) \cdot 5 = -5\sin(5x)$$
ขั้นตอนที่ 4: ใช้ Product Rule
$$\begin{align} \frac{dy}{dx} &= u'v + uv'\\ &= 6x\cos(3x^2) \cdot \cos(5x) + \sin(3x^2) \cdot (-5\sin(5x))\\ &= 6x\cos(3x^2)\cos(5x) - 5\sin(3x^2)\sin(5x) \end{align}$$
คำตอบ:

$\frac{dy}{dx} = 6x\cos(3x^2)\cos(5x) - 5\sin(3x^2)\sin(5x)$

ตัวอย่างที่ 6 ท้าทาย

โจทย์:

หาอนุพันธ์ของ $f(x) = \frac{e^x \sin x}{x^2 + 1}$ (ใช้ทั้ง Product Rule และ Quotient Rule)

วิธีทำ:

วิธีที่ 1: Quotient Rule โดยตรง

ให้ $u = e^x \sin x$ และ $v = x^2 + 1$

หา $u'$ ด้วย Product Rule: $u' = e^x \sin x + e^x \cos x = e^x(\sin x + \cos x)$

หา $v'$: $v' = 2x$

$$\begin{align} f'(x) &= \frac{u'v - uv'}{v^2}\\ &= \frac{e^x(\sin x + \cos x)(x^2 + 1) - e^x \sin x \cdot 2x}{(x^2 + 1)^2}\\ &= \frac{e^x[(x^2 + 1)(\sin x + \cos x) - 2x\sin x]}{(x^2 + 1)^2}\\ &= \frac{e^x[x^2\sin x + \sin x + x^2\cos x + \cos x - 2x\sin x]}{(x^2 + 1)^2}\\ &= \frac{e^x[(x^2 - 2x + 1)\sin x + (x^2 + 1)\cos x]}{(x^2 + 1)^2} \end{align}$$
คำตอบ:

$f'(x) = \frac{e^x[(x^2 - 2x + 1)\sin x + (x^2 + 1)\cos x]}{(x^2 + 1)^2}$

หรือ $f'(x) = \frac{e^x[(x-1)^2\sin x + (x^2 + 1)\cos x]}{(x^2 + 1)^2}$

ตัวอย่างที่ 7 ท้าทาย

โจทย์:

ใช้ Logarithmic Differentiation หาอนุพันธ์ของ $y = x^x$ โดยที่ $x > 0$

วิธีทำ:

ขั้นตอนที่ 1: ใช้ ln ทั้งสองข้าง
$$\ln y = \ln(x^x) = x \ln x$$
ขั้นตอนที่ 2: หาอนุพันธ์ทั้งสองข้างเทียบกับ $x$

ใช้ Chain Rule ที่ข้างซ้าย และ Product Rule ที่ข้างขวา:

$$\frac{1}{y} \cdot \frac{dy}{dx} = \frac{d}{dx}(x \ln x) = 1 \cdot \ln x + x \cdot \frac{1}{x} = \ln x + 1$$
ขั้นตอนที่ 3: แก้หา $\frac{dy}{dx}$
$$\begin{align} \frac{dy}{dx} &= y(\ln x + 1)\\ &= x^x(\ln x + 1)\\ &= x^x(1 + \ln x) \end{align}$$
คำตอบ:

$\frac{dy}{dx} = x^x(1 + \ln x)$

หมายเหตุ: ไม่สามารถใช้ Power Rule ได้เพราะทั้งฐานและเลขชี้กำลังเป็นตัวแปร!

แบบฝึกหัด

ระดับพื้นฐาน

ข้อ 1:

หาอนุพันธ์ของ $f(x) = 5e^x - 3^x + \ln x$

เฉลย:

$$\begin{align} f'(x) &= 5e^x - 3^x \ln 3 + \frac{1}{x} \end{align}$$

คำตอบ: $f'(x) = 5e^x - 3^x \ln 3 + \frac{1}{x}$

ข้อ 2:

หาอนุพันธ์ของ $g(x) = 2\sin x - 3\cos x + 4\tan x$

เฉลย:

$$\begin{align} g'(x) &= 2\cos x - 3(-\sin x) + 4\sec^2 x\\ &= 2\cos x + 3\sin x + 4\sec^2 x \end{align}$$

คำตอบ: $g'(x) = 2\cos x + 3\sin x + 4\sec^2 x$

ข้อ 3:

หาอนุพันธ์ของ $h(x) = e^{5x}$

เฉลย:

ใช้ Chain Rule:

$$h'(x) = e^{5x} \cdot 5 = 5e^{5x}$$

คำตอบ: $h'(x) = 5e^{5x}$

ข้อ 4:

หาอนุพันธ์ของ $y = \ln(x^2 + 3x)$

เฉลย:

ใช้ Chain Rule กับ ln:

$$\frac{dy}{dx} = \frac{1}{x^2 + 3x} \cdot (2x + 3) = \frac{2x + 3}{x^2 + 3x}$$

คำตอบ: $\frac{dy}{dx} = \frac{2x + 3}{x^2 + 3x}$ หรือ $\frac{2x+3}{x(x+3)}$

ข้อ 5:

หาอนุพันธ์ของ $f(x) = \sin(4x - 1)$

เฉลย:

ใช้ Chain Rule:

$$f'(x) = \cos(4x - 1) \cdot 4 = 4\cos(4x - 1)$$

คำตอบ: $f'(x) = 4\cos(4x - 1)$

ระดับท้าทาย

ข้อ 6:

หาอนุพันธ์ของ $g(x) = e^{x^2} \ln x$

เฉลย:

ใช้ Product Rule: $u = e^{x^2}$, $v = \ln x$

$u' = e^{x^2} \cdot 2x = 2xe^{x^2}$ (Chain Rule)

$v' = \frac{1}{x}$

$$\begin{align} g'(x) &= u'v + uv'\\ &= 2xe^{x^2} \cdot \ln x + e^{x^2} \cdot \frac{1}{x}\\ &= 2xe^{x^2}\ln x + \frac{e^{x^2}}{x}\\ &= e^{x^2}\left(2x\ln x + \frac{1}{x}\right) \end{align}$$

คำตอบ: $g'(x) = e^{x^2}\left(2x\ln x + \frac{1}{x}\right)$

ข้อ 7:

หาอนุพันธ์ของ $y = \frac{\ln x}{e^x}$

เฉลย:

ใช้ Quotient Rule: $u = \ln x$, $v = e^x$

$u' = \frac{1}{x}$, $v' = e^x$

$$\begin{align} \frac{dy}{dx} &= \frac{u'v - uv'}{v^2}\\ &= \frac{\frac{1}{x} \cdot e^x - \ln x \cdot e^x}{(e^x)^2}\\ &= \frac{e^x\left(\frac{1}{x} - \ln x\right)}{e^{2x}}\\ &= \frac{1 - x\ln x}{xe^x} \end{align}$$

คำตอบ: $\frac{dy}{dx} = \frac{1 - x\ln x}{xe^x}$

ข้อ 8:

หาอนุพันธ์ของ $h(x) = \sin^3(2x)$ (ซึ่งหมายถึง $[\sin(2x)]^3$)

เฉลย:

ใช้ Chain Rule ซ้อนกัน:

ฟังก์ชันนอกสุด: $u^3$ มีอนุพันธ์ $3u^2$

ฟังก์ชันกลาง: $u = \sin(2x)$ มีอนุพันธ์ $\cos(2x) \cdot 2 = 2\cos(2x)$

$$\begin{align} h'(x) &= 3[\sin(2x)]^2 \cdot \frac{d}{dx}[\sin(2x)]\\ &= 3\sin^2(2x) \cdot 2\cos(2x)\\ &= 6\sin^2(2x)\cos(2x) \end{align}$$

คำตอบ: $h'(x) = 6\sin^2(2x)\cos(2x)$
